# The words of interpretive code that no test and no scenario runs, and why.
# tests/word_coverage.py --write writes this file and keeps each reason;
# `make line-coverage` measures again and holds the tree to it.
#
# Counted: every word of every table of interpretive code in src/ (each a
# struct interpretive_code), as the interpreter took it in the case tests
# and the scenarios: an order pair by its orders (the left one, the right
# one), a branch by its two outcomes, a store code, an operand in line
# with the code by whether a program that ran its order read it, and a
# constant among the code by whether a program read it that took an
# operand naming it. (A read alone is not enough: a made-up state's
# address comes to any word of the rope.) A word stands here if any of
# that was not seen: its line says what, then the listing's line.
#
# LM: 447 tables: 11434 words, 11410 of them run wholly (99.8%).
#     orders: 6957 of 6957 run; store codes: 1324 of 1324; operands: 5912 of 5936 read;
#     branches: 524 of 524 run, 524 both ways.
#     (1 more in the tables are basic instructions, not counted.)
#   The scenarios alone: 11434 words, 8424 of them run wholly (73.7%).
#     orders: 5366 of 6957 run; store codes: 1018 of 1324; operands: 4458 of 5936 read;
#     branches: 412 of 524 run, 140 both ways.
#   From 93 programs. 43939 right orders ran that the recorder found no pair for,
#   taken or behind LOC: counted nowhere.
#   They were noted at 7 places: 6 are the CADR after a TC USPRCADR, where
#   basic code has the interpreter run one routine and EXIT.
#   The others: 10,2173 (TCF VXV).
# CM: 520 tables: 13864 words, 13836 of them run wholly (99.8%).
#     orders: 8336 of 8336 run; store codes: 1544 of 1544; operands: 7284 of 7312 read;
#     branches: 737 of 737 run, 737 both ways.
#   The scenarios alone: 13864 words, 10692 of them run wholly (77.1%).
#     orders: 6687 of 8336 run; store codes: 1234 of 1544; operands: 5800 of 7312 read;
#     branches: 606 of 737 run, 240 both ways.
#   From 84 programs. 55486 right orders ran that the recorder found no pair for,
#   taken or behind LOC: counted nowhere.
#   They were noted at 7 places: 3 are the CADR after a TC USPRCADR, where
#   basic code has the interpreter run one routine and EXIT.
#   4 are at an indexed store code, where no pair's order waits: a made-up
#   state's index can make the store write EDOP itself.
#
# By reason:
#   basic: 35 words in 5 stretches
#   unnamed: 6 words in 4 stretches
#
# A reason in brackets is one of these:

[basic] Not the interpreter's to read: basic instructions read the word. The
    check finds one in the mission's listing that names a word of the
    stretch, or a TC as the word before it (whose routine reads the words
    after its call). The line measure counts the C of those instructions.
[impossible] No state brings the interpreter to the word, or the branch the
    other way: the program's own words rule it out, and the reason says how.
    An argument, not a run.
[never] No program brings the state, though the words of the table do not
    rule it out: the reason rests on what the rest of the program stores or
    calls, and says what was looked at.
[unnamed] A constant that no word of the mission's listing names. The check
    looks: the constant has a name, and no instruction, order or address of
    the listing has that name as its operand. An address reckoned from
    another name could still come to it, and the reason says what stands
    beside it.
