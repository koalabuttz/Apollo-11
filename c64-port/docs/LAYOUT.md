include/layout.h and src/layout.c provide bounded raw views of the sole canonical 2,048-word image. A physical source alias selects image.words[physical_word]; it creates no second storage object. These are raw storage operations; instruction-specific sign correction, zero-source behavior, editing registers, counters and device I/O remain the responsibility of the native services which use the image.
