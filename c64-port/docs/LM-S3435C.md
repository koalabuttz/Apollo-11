# S34/35.2's integration head and S34/35.5: the TPI targeting display

Lane E. Milestone `lm-s3435c`.

## Scope

From `Luminary099/P34-35_P74-75.agc`, bank 35 `03306`-`03326`,
`03367`-`03376` and `03522`-`03605`: 77 words on 77 source lines. Ten
interpretive routines are keyed by LOC under BANKSET at NEWOPS. Eight basic
routines are keyed by Z. All use the control-transfer ABI
(`include/agc_transfer.h`, `docs/NATIVE_TRANSFER_ABI.md`).

- **S34/35.2 (`35,3306`):** STQ SUBEXIT. It then pushes VPASS3, RPASS3,
  INTIME, TPASS4 and TWOPI. BHIZ NN: with NN zero it goes straight to the
  CALL INTINT (lm-s3435b). Otherwise it pops TWOPI and pushes ZEROVECS in
  its place (precision rather than conic) first.
- **S34/35.2's INITVEL return (`35,3367`):** CALL LOMAT (lm-s3435).
- **S34/35.2's LOMAT return (`35,3371`):** rotates DELVEET3 through the
  work-area local-vertical matrix at 0D (MXV), VSL1, then STCALL DELVLVC to
  the CADR in SUBEXIT.
- **S34/35.5 (`35,3522`):** STQ SUBEXIT. BON FINALFLG goes to FLAGON;
  otherwise it sets UPDATFLG and goes to FLAGOFF.
- **FLAGON (`35,3531`):** CLEAR NTARGFLG, VLOAD DELVLVC, STORE GDT/2, EXIT.
- **FLAGON +5 (`35,3536`), basic:** CAF V06N81, TC BANKCALL to GOFLASH.
- **GOFLASH's returns (`35,3541`-`3543`), basic:** terminate (TC
  GOTOPOOH), proceed (on into the target check), recycle (TC back to FLAGON
  +5).
- **Target check (`35,3544`), basic:** in EBANK7 it sums the differences
  between GDT/2 and DELVLVC into L, five words down to Q `+0`. With L zero it
  goes to INTPRET. Otherwise it goes to UPFLAG NTARGFLG first.
- **UPFLAG's return (`35,3565`), basic:** TC INTPRET.
- **The target check's INTPRET return (`35,3566`):** BOFF NTARGFLG goes to
  NOCHG. Otherwise it calls S34/35.3 (lm-s3435b).
- **NOCHG (`35,3572`):** CLEAR XDELVFLG, VLOAD DELVEET3, STORE DELVSIN, and
  on into FLAGOFF.
- **FLAGOFF (`35,3576`):** CALL S34/35.4 (lm-s3435).
- **FLAGOFF's S34/35.4 return (`35,3600`):** EXIT.
- **FLAGOFF exit (`35,3601`), basic:** CAF V06N59, TC VNPOOH.
- **VNPOOH's return (`35,3603`), basic:** TC INTPRET.
- **VNPOOH's INTPRET return (`35,3604`):** GOTO the CADR in SUBEXIT.

S34/35.2's ACOS and its Lambert setup (`35,3327`-`3366`) wait on Lane D1b's
ACOS body. They are a stop here.

Each run ends at the first point outside the routines and the ones it reuses
(lm-s3435b, lm-s3435, lm-p34's basic routines and the native INTER-BANK
routines). That is a NEWOPS outside their interpretive code (INITVEL,
INTSTALL, or a caller's return), GOFLASH through BANKCALL, UPFLAG, GOTOPOOH,
INTPRET, or UNIT's POODOO1 (`tests/lm_s3435c_cases.c`, `lm_s3435c_stop`).

Every interpretive pair is compiled with the shared bodies
(`src/lm_interp_steps.c`, `src/lm_interp_orders.c`). MXV runs the compiled
matrix phases (`src/matrix_native.c`, column 0) on the work-area matrix
through the new shared helper `src/lm_work_matrix.c`, with the ADDRWD bias
that lm-midgim's GET.LVC uses. ZEROVECS is read from the certified rope.
TWOPI (`35,3731`) is outside the certified spans, so it is a literal checked
against the address the formation leaves (ADDRWD `03731`, FB 35). Each basic
instruction is one `ai_*` register effect on the image, in source order.

Interpretive routines admit a canonical NEWOPS image at their LOC in FB 35
meeting all of these conditions, and otherwise return `EXEC_OUT_OF_SCOPE`
with the image unchanged:

- EB and BB coherent, with BANKSET = BB;
- INTBIT15 set;
- EDOP, ZERO and NEWJOB zero;
- MODE `+0`, `+1` or vector;
- the VAC one of the five, with PUSHLOC no further than 40D into it;
- IRQ 0 or 1, and an allowed SUPERBNK;
- every word 15 bits.

Basic routines admit Z at their entry in FB 35, with EB and BB coherent,
ZERO zero, IRQ 0 or 1, an allowed SUPERBNK and every word 15 bits.

## Evidence

Hashes are in `evidence/lm-s3435c/SHA256.json`. Bulk files are assets of the
`evidence-lm-s3435c` release (`python3 tools/evidence.py fetch lm-s3435c`).

- **Source-to-native map and independent assembly comparison.**
  `python3 tools/lm_s3435c_source.py` reassembles the unchanged file with the
  pinned yaYUL. The rope equals the certified fixed-data rope.
- **Oracle.** `tools/lm_s3435c_reference.c` (GPL, host only) runs the
  unchanged Luminary099 in the pinned yaAGC hardware-DV variant from 18432
  entries, 1024 per routine, to the same stops.
  - The entries sit over poisoned debris with any vectors, matrix and flags.
    NN is zero in one S34/35.2 entry in two, so BHIZ takes its branch.
    GDT/2 equals DELVLVC in one target check in two, so both outcomes run.
  - They cover every VAC, MODE, IRQ and allowed SUPERBNK setting, and
    PUSHLOC as far as each routine's pushes leave room.
  - QPRET and SUBEXIT are each one of the real callers' returns (`35,2673`
    and `2756` for S34/35.2; `35,2721` and `2760` for S34/35.5), or a CADR
    in banks 2-27.

  `tools/lm_s3435c_differential.py` requires every native trampoline run to
  produce the same 2048 erasable words, interrupt state and SUPERBNK. It pins
  the stream identity (`lm-s3435c-source-stream.json`, SHA256
  `3b7c3bf4...4c04c8`) and archives the stream
  (`lm-s3435c-reference.snapshots.bin.xz`). `lm-s3435c-proof.json` lists the
  stops per routine. No sampled entry reaches UNIT's alarm.
- **Host and sanitizer results.** Run `make test-lm-s3435c sanitize-lm-s3435c`.
  The strict build and the ASAN/UBSAN build each pass 18667 checks:
  - all 18432 frozen digests;
  - every run ending at one of the stops;
  - 196 admission guards: EB, BB, FB, ZERO, 16-bit words, SUPERBNK and IRQ
    for every routine, and VAC, MODE, INTBIT15, EDOP, NEWJOB, BANKSET and
    PUSHLOC for the interpretive ones.

  See `lm-s3435c-checks.log`.
- **C64 execution results.** Run `make vice-lm-s3435c`. Three PRGs each
  register only the routines their cases reach:
  - group 1: S34/35.2, with lm-s3435b's INTINT (256 cases);
  - group 2: S34/35.2's LOMAT return (256 cases);
  - group 3: FLAGON, FLAGOFF's S34/35.4 return, VNPOOH's INTPRET return and
    the eight basic routines, with lm-p34's basic routines and INTER-BANK
    (352 cases).

  Each keeps the image in the RAM under KERNAL ROM (`$01=$35`). The case
  generator is integer-only, so the C64 builds the same entry images as the
  host. In VICE (PAL, stock ROMs) the three PRGs pass 256, 256 and 352
  checks with no failures (`lm-s3435c-results.json`).

## Limits

- Five entries are host-only: S34/35.2's INITVEL return, S34/35.5, the
  target check's INTPRET return, NOCHG and FLAGOFF. Their runs go on through
  LOMAT and MXV, S34/35.3 with VXM and INTINT, or S34/35.4 with NOVRWRT's
  MXV, and outgrow C64 RAM (each MXV/VXM site costs about 16 KB). Each of
  those routines runs on the C64 here or in lm-s3435 and lm-s3435b.
- S34/35.2's ACOS and Lambert setup (`35,3327`-`3366`), ELCALC and P34/P35
  themselves are not covered. The file stays `partial`.
- Numerical validity is the original's. No wider claim is made.
