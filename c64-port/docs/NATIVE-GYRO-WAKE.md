# Native gyro caller restoration and resleep

`imu_gyro_wake` executes each original mission's GWAKE body after actual basic-job restoration. When LGYRO is positive, it preserves the saved command/caller pair and branches to the true JOBSLEEP entry. When LGYRO is +0, it clears MPAC+2, restores BUF2 from MPAC, preserves the displaced BUF2 minor in raw L, loads one centisecond and calls WAITLIST at GWAKE2. The complementary helper composes the frozen original basic-sleep or IMUPULSE WAITLIST adapter. Successful free registration returns at the same source boundary accepted by the unchanged `imu_pulse_finish` reservation/command-agreement/bank-return body.

The busy helper runs the real Executive core search and restores a selected basic job or reaches idle ADVAN. It stops before the selected job body or idle wait loop. The numerical GWAKE and service returns are native ABI boundaries with no invented Executive check or scheduling seam. Canonical words remain authoritative and caller producer exclusion spans the composed operation.

All 262,144 states (two missions, two checkpoints, 65,536 inputs per context) match unchanged original assembly, strict native and complete ASAN/UBSAN bytes. Each comparison includes all 2048 canonical words, raw A/L, IRQ, SUPER and channels11/12/14. Inputs vary initialized +0/positive LGYRO, raw incoming registers, saved caller pairs, legal saved basic banks, all cores, a selected source basic job versus idle, queue time and unowned poisoned data. This constructor corpus is not an exhaustive Cartesian state-space claim. The original instruction stop test distinguishes fixed banks when a source Executive search visits a PC numerically equal to the WAITLIST return.

The contract requires nonnull exclusively owned ordinary canonical image/I/O, original GWAKE PC in bank07, coherent EB/BB/SUPER and ZERO0, initialized LGYRO>=+0, quiescent device counters, and the documented source domains of the composed sleep/WAITLIST helpers. Negative initialized LGYRO contexts, asynchronous counter producers, arbitrary unsupported queues or saved interpreted contexts are not qualified by this packet. Unsupported downstream results do not promise whole-composition rollback. The immutable helpers retain their existing independent contracts and bytes.

Four actual C64 PRGs compare 32 source-only frozen complete states each. All 128 states passed stock PAL VICE, with retained load maps, no compiler zero-page allocation and checked hardware/software stack guards. The largest diagnostic is 15,091 bytes; measured maxima are 22 hardware-stack bytes and 742 software-stack bytes. The frozen helper signedness warnings remain visible under the established target exception; strict host builds keep warnings as errors.

Nine original containing-file words per mission (GWAKE and LGWAKE) are independently mapped to the byte-original ropes, preserving the frozen IMU audit. The original/strict/sanitized streams share one deterministic XZ object per context with decoded identity in the proof ledger. Source basic-sleep, WAITLIST and IMUPULSE registration/reservation dependencies are immutable.

This closes the bounded GWAKE caller restoration/resleep body. Physical gyro pulses, active-channel augmentation, selected job bodies and scheduler/interrupt execution remain separate boundaries. It does not certify the entire IMU/RTB file or either application.
