# Translate Comanche055 P30-P37

Lane E (targeting). Milestone `cm-p30-p37`. How the routines are made and checked: `docs/INTERP-COMPILE.md`.

`Comanche055/P30-P37.agc` (`src/cm_p30_p37.c`) is native C in full. All 374 words, in banks 02, 31, 32 and 35, are compiled by `tools/interp_compile.py` into 90 routines of the control-transfer ABI. The spec is `cm-p30-p37` in `tools/interp_specs.py`.

The file holds:
- P30 and P31, the external delta-V programs, with their displays;
- S30.1 and S31.1, which the targeting programs call;
- DELRSPL and AUGEKUGL, the P37 splash-error and entry-range functions;
- AVFLAGA, AVFLAGP and P20FLGON.

Each routine runs the file from its entry, or from where it resumes, to the point where control leaves the file.

## Spec keys

- **`ebank: 4`.** AVFLAGA, AVFLAGP and P20FLGON save Q in SUBEXIT (E4,1770) and return through it with EB 4.
- **`fixed_index`.** K1K2LOOP reads V(32K), YK1K2 and CK1K2 indexed by X1. Every address from X1 0 to 12 is a `K` array. The states pin X1 to the values LOOPSET, K2CALC and K1K2LOOP see, and S1 to 2.
- **RGEXIT and P30/31RT.** These hold fixed returns where END45's GOTO RGEXIT and FLASHMGA's TC P30/31RT run them. A caller return in 02000-03777 would read as an erasable CADR, and GOTO's erasable fetch can chain without end, as the hardware would.
- **Flight flags (#321).** `superbank_bit`, `trusted_image`, `index_carry16` and `image_w` (docs/INTERP-COMPILE.md): the C64 and flight builds read fixed operands in FB 30-37 unless the superbank bit is set, skip the whole-image scan in flight, take INDEX's end-around carry in 16 bits and address the fixed image directly.

Destinations outside the file stop with `EXEC_UNMAPPED` until their files have routines.

## Evidence

Hashes: `evidence/cm-p30-p37/SHA256.json`. Bulk files are assets of the `evidence-cm-p30-p37` release.

- **Source map.** `cm-p30-p37-source-map.json` lists every word with the routine that compiles it.
- **Independent assembly comparison.** `make cm-p30-p37-differential` runs 512 states per routine (73,216 cases). All equal yaAGC in Z, all 2,048 erasable words and the interrupt-enable state. Every 128th case is frozen in `tests/cm_p30_p37_vectors.h`.
- **Host and sanitizer results.** `make test-cm-p30-p37 sanitize-cm-p30-p37` runs the frozen cases (`cm-p30-p37-host.log`).
- **C64 execution results.** `make vice-cm-p30-p37` runs six diagnostics with 179 cases (`cm-p30-p37-vice.log`).
