# Translate Comanche055 P32-P33_P72-P73

Lane E (targeting). Milestone `cm-p32-p33`. How the routines are made and checked: `docs/INTERP-COMPILE.md`.

`Comanche055/P32-P33_P72-P73.agc` (`src/cm_p32_p33.c`) is native C in full. All 882 words, across 16 banks, are compiled by `tools/interp_compile.py` into 128 routines of the control-transfer ABI. The spec is `cm-p32-p33` in `tools/interp_specs.py`.

The file holds:
- P32/P72 (CSI) and P33/P73 (CDH), with their displays;
- the CSI search: CSI/A through CSINEXT4, NEWTN and SCNDSOL;
- S32/33.1, S32/33.X, CDHMVR, ROTATE, INTINT2C and INTINT3P.

## Compiler and spec additions

- **Shift counts.** A shift's operand word is its count (`SL 14D` is 020217), not an address, so it is never a fixed operand.
- **SINE and COSINE.** These spellings compile like SIN and COS.
- **SLOAD\* of a fixed table.** ALMXIT's `SLOAD* ALARM/TB -1,1` reads the word at the effective address the spec's `fixed_index` allows (alarms 1-7).
- **`self_loops`.** A branch back to the routine's own start loops inside the routine (at most 4,096 passes before it returns to the run loop). P32/P72F subtracts 60MIN until the time goes negative, which can take hundreds of passes, more than the run loop's 200-step limit.
- **`superbank_bit` and `trusted_image`** (#321). An indexed read of a fixed operand in FB 30-37 refuses only when the superbank bit is set, at the routine's entry, before any order writes state. Flight builds skip the whole-image scan at entry.
- **`fixed_index`.** PMINE -2,1 with X1 = RTX1 (-2 earth, -10 moon) reads PMINE or PMINM.
- **States.**
  - EB 7, since CSIALRM (TITER) and RTX1 are E7 words.
  - CSIALRM is an alarm number 1-7, and RTX1 is -2 or -10.
  - PUSHLOC is pinned low where ROTATE and ADVANCE's returns push vectors, so the pushes don't run over X1 through QPRET.

## Evidence

Hashes: `evidence/cm-p32-p33/SHA256.json`. Bulk files are assets of the `evidence-cm-p32-p33` release.

- **Source map.** `cm-p32-p33-source-map.json` lists every word with the routine that compiles it.
- **Independent assembly comparison.** `make cm-p32-p33-differential` runs 512 states per routine (208,384 cases, 407 routines). All equal yaAGC in Z, all 2,048 erasable words and the interrupt-enable state. Every 256th case is frozen in `tests/cm_p32_p33_vectors.h`.
- **Host and sanitizer results.** `make test-cm-p32-p33 sanitize-cm-p32-p33` runs the frozen cases (`cm-p32-p33-host.log`).
- **C64 execution results.** `make vice-cm-p32-p33` runs 41 diagnostics with 477 cases (`cm-p32-p33-vice.log`). They take every branch arc the host cases take (`cm-p32-p33-c64-cover.json`, `--cover-check` verified); two rows are truncated at the 24,2025 cut, where the yaAGC run of the same case also stops.
