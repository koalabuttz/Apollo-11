# Comanche idle interrupt and resume

`cm_idle_interrupt_enter` translates the actual automatic T3 interrupt at original ADVAN01,3231 (`CCS NEWJOB`) and its 04014 lead-in through T3RUPT2 at01,3423. `cm_idle_interrupt_resume` implements original hardware RESUME05341 through restored PC03231 and records that the genuine compiled idle continuation remains pending. The saved BRUPT word010067 remains passive data; no saved instruction is decoded or executed by native C.

The final domain requires coherent physical FB02000, ordinary Q/QRUPT0000..07777, all eight E-banks, all eight SUPER forms, ZERO+0 and valid Boolean interrupt metadata. Incoming A must have no overflow when interrupt delivery is accepted; raw L is corrected as in the hardware frame. Delivery defers without mutation when interrupts are disabled, an ISR is already active, or A overflows. Resume requires the genuine saved03232/010067 frame and active ISR metadata; both restored interrupt-enable states are preserved. All other canonical words and all thirteen explicit I/O fields are compared, including their unchanged values. Callers retain producer exclusion and invoke the compiled ADVAN continuation after resume; this foundation does not implement the task body or invent a flight job.

4,096 full original-layout source cases match strict native C and the entire ASAN/UBSAN stream, SHA256 `2089ff7deb06d344af6fa6a8327de0b27ba5cafb5d477b10a6bad390f381a408`. Each checkpoint retains all 2,048 canonical words, thirteen external latches, and source InIsr/substitute metadata. Fresh assembly is pinned to byte-original CM rope `6e3150ae9b43535237e10f565205d1f65e6d60cafbe8935be598e03e9810b061`; originals remain untouched. Separate guard checks prove deferred and rejected calls leave every object unchanged.

Stock PAL C64 executes 64 representative source checkpoints through actual disk overlays. The checker compares every source field through source-derived fingerprints, directly compares two full 2,063-field samples, and externally compares the final entire canonical image. Both incoming C64 I states and ROM mapping are preserved around calls. The native control payload is diagnostic module 246, input 254 and checker 255; these IDs make no production registry claim. The actual AGC interrupt is translated software control; this diagnostic does not claim a physical C64 ISR has been wired into the production mission loop.

An initial broader standalone hardware-frame experiment also passed original source and C64. Its arbitrary restored fixed-bank cases were narrowed before release to the genuine idle program bank; both restored IRQ states were then added and the complete source/SAN/C64 proof was rerun. Its original code, full streams and target artifacts remain in `evidence/cm-idle-interrupt-broad-hardware-first-pass/`. This historical experiment does not expand the final caller contract or application coverage.
