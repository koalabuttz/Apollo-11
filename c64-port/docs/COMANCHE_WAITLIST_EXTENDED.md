# Comanche WAITLIST, TWIDDLE and alarm entry states

`cm_waitlist_extended` translates original WAITLIST05245 and TWIDDLE05235 through the actual caller return or actual POODOO05721/BAILOUT07755 entry. All 2048 canonical erasable words, raw A/L/Q and explicit SUPERBNK/IRQ match original assembly. The caller supplies the compiled inline task literal; no executable source word is fetched or decoded. TWIDDLE derives its BBCON from the current BBANK/SUPERBNK and returns caller+1 rather than WAITLIST's caller+2.

Both signed zero and all ordinary negative delays enter POODOO with1204 at the original Q05262 literal. Full queues enter BAILOUT with1203 at Q03376 either before insertion or after actual interval/list shifts have displaced the final non-dummy task; no rollback occurs. Alarm bodies remain later source continuations. The native explicit alarm status does not invent an I/O latch write before the original alarm entry. The exact old WAITEXIT/WAITBANK scratch, raw accumulator residue, L, Q and physical bank state remain source faithful.

All ordinary positive source delay words1..16383 are supported, including the134-word range16250..16383 previously outside the bounded helper's documented maximum. The private source scheduler retains raw overflow/CCS arithmetic while the canonical wrapper supplies all original register/scratch effects. A successful discarded dummy may have any valid source bank; its actual bank debris is retained in WAITBANK. Current source PC, physical bank consistency, non-overflowing ordinary A and explicit selector are checked before mutation. Existing alarm state and malformed source contexts are unsupported; this stage does not execute POODOO/BAILOUT restart cleanup.

The independent host oracle executes the byte-original Comanche WAITLIST/Executive overlays with nine/five indentation-only pseudo-label repairs on pinned VirtualAGC1b5d6474841a7ab53237ead070f76f35f162f68d. The whole normalized rope SHA2562ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79 equals the supporting baseline. Source patches and hashes are retained. Supporting ALTVAR/R53FLBIT differences are unused. Counter driver words are zero and the oracle scaler is frozen; no output normalization occurs.

All 2048 complete source/native2051-value states match SHA2562fc54133599c61714b8a7ce2966cfaf3e76ec3eb6f06b5773f089f55a7b35e56. Cohorts cover both entries, +/-zero/negative delays, successful insertion, equal/adjacent deadlines, pre/post-insertion overflow, the whole upper positive-delay range and varied discarded-dummy banks. Strict host and ASAN/UBSAN pass the complete corpus. Stock PAL C64 passes128 representative complete-state fingerprints and two full2051-value samples, mailboxa500008000; hardware/software stack extents18/80bytes.
