# CM clock/display task groups

`cm_clocktask_phase` translates actual CLOKTASK at `24,3260`, its post-WAITLIST continuation `24,3301`, and SETTB6 at `24,3315` as three explicit source groups. The enabled timer computes source TIME2/TIME1 minus TIG into TTOGO using original double-add semantics and returns at WAITLIST with 100 centiseconds. Disabled timers clear original phase6 protection and finish at TASKOVER. The continuation selects source CLOCKJOB via NOVAC or DYNDISP via FINDVAC according to original NVWORD1 tests, or writes -TIME1 to TBASE6 and finishes. Original raw registers, banks, Q/Z, phase scratch and external IRQ/SUPERBNK are exact. Physical bank24/E7 is required. CLOCKJOB/DYNDISP executable bodies and the service composition between groups remain separate milestones.

The oracle is host-only GPL Virtual AGC at `1b5d6474841a7ab53237ead070f76f35f162f68d`. The fixture overlays byte-preserved original translated sections onto pinned corrected supporting sources. The service fixture's indentation-only repairs and pinned-support domain are recorded in `COMANCHE_RESTART.md`; the assembled rope is `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`. Historical originals are untouched. This qualification does not silently adopt the separate globally-original ERASABLE_ASSIGNMENTS domain: that source has the documented stray `-16` line and different ALTVAR/R53FLBIT addresses; none of these groups uses those symbols.

Each comparison includes every 2048 physical erasable word, raw A/L, source Z/Q/banks and exit status. Autonomous drive-counter inputs are held zero, source scaler updates are frozen, and no output words are normalized. Native code is MIT, uses the sole canonical image, and contains no AGC decoder or executable rope. External SUPERBNK/IRQ latches remain separate metadata. Source-selected service calls require resident composition after the current C frame returns. The standalone diagnostic proves its documented states and resource bounds, not whole-application overlay fit or WCET.

1536 independent original-source cases and the host ASan/UBSan diagnostic pass; each state is checked against its frozen full-image fingerprint plus two complete 2051-value states. Snapshot SHA256 is `cfe2235de2d341266cbd3f6e953221ff12c2f49296864402412b87e88b6470e3`.

The separate entry-task fixture adds original CM_ENTRY_DIGITAL_AUTOPILOT and P40-P47 with one and seven indentation-only pseudo-label repairs respectively, zero semantic edits. The full rope equals the pinned-support baseline. Their original SHA256 identities are `14f76028ec691d72b326c551b4676da928c1c744eb3a2aff817b582d70df9e1d` and `5861ed6fd0b6b773c6c0ee5ab0099fcf9509a8fa1263823609ad844ec263f834`, retained in `evidence/cm-entry-tasks-source-audit.json`.
