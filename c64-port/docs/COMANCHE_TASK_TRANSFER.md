# Comanche canonical task dispatch and finish

`cm_task_transfer` translates original T3RUPT2 at `01,3423` through actual selected-task DTCB, and TASKOVER at `05324` through either that next task transfer or the hardware RESUME entry at `05341`. All original list/time shifts, RUPTAGN overflow encoding, raw A/L, saved-Q exchange, ARUPT/LRUPT debris, physical banks and external SUPERBNK/IRQ effects are retained. No selected body is skipped. The resident resolves the returned source Z/BB/SUPERBNK to an actual compiled native body after this C frame returns.

A dispatch entry requires original bank1/E3; task completion requires source RUPTAGN=1 or -0 and a valid interrupt-save frame. Q and saved QRUPT are ordinary 12-bit source return addresses. The 1024 whole-image cases select actual SETJTAG/CLOKTASK/TIG-0/SVCT3 pairs, exercise both task completion branches, all bank/latch encodings and poisoned erasable guards. Hardware RESUME itself and the original interrupt lead-in remain explicit resident composition work; the proof stops before executing the saved instruction.

All 1024 original-source cases compare every 2048 physical erasable word, raw A/L, source Z/Q/banks, external SUPERBNK/IRQ and exit status. Host and ASan/UBSan pass all 1024 frozen full-image fingerprints and two complete 2051-value states. Snapshot SHA256 is `f8c40a7278e11db040e58bc2fc012848df5e9c510e3fba2025120db4ebcec48b`. Counter-drive inputs are held zero, source scaler updates are frozen, and no output word is normalized. The GPL oracle runs only on the host, using Virtual AGC `1b5d6474841a7ab53237ead070f76f35f162f68d`; original WAITLIST is byte-preserved except its audited nine indentation-only pseudo-label repairs. The pinned corrected supporting-source domain is documented in `COMANCHE_WAITLIST.md`; rope SHA256 is `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`. Historical originals are untouched.

PAL C64 passes 128 representative complete-image fingerprints and one complete 2051-value state: mailbox `a500008000`, PRG 17916 bytes, text 5582, rodata 12320, BSS 4122, image end `$5e15`, hardware/software stack extents 20/151 bytes, no extra zero-page sections. Native code is MIT, owns the sole canonical image, retains no persistent private flight state or suspended overlay frame, and contains no source decoder. Producer exclusion is caller-owned. This standalone proof does not establish whole-application overlay fit or WCET.
