# Native LM numeric keyboard entry

`dsky_charin_number` implements actual Luminary099 CHARIN40,2077 through NUM, GETINREL, DSPIN, octal cyclic editing or decimal SHORTMP accumulation, ENDNMTST and MORNUM to the real ENDOFJOB5155 entry. Final R1/R2/R3 decimal input runs the source DMP fraction conversion and sign exchange, retaining every scratch word and A/L/Q effect. VERB/NOUN input stays whole. Negative DSPCOUNT blocks further input after the actual CHARIN lock/lamp path. No AGC opcode is decoded or executed by the native body.

The qualified input keys are1..9 and zero's hardware code020. Live DSPCOUNT0..19 except15 selects V/N or R1/R2/R3. DECBRNCH lowbits0..2 select octal, positive decimal, or negative decimal; live8/9 require a decimal branch. Octal input accepts ordinary register words; decimal input accepts V/N0..99 and R1/R2/R3 prior sums0..9999. All relevant DSPTAB entries must be nonzero to avoid the original CCSHOLE branch. Bank40/SUPER100 retains any EB0..7. The caller excludes producers. Unsupported inputs leave canonical image and I/O untouched. Illegal-key operator-alarm paths, signs/clear/enter commands and Executive completion are separate bodies.

The independent oracle executes8192 actual original checkpoints. Every2048 physical word, SUPER/IRQ, physical channel11 latch and event flag matches,2052 fields per checkpoint. The corpus includes all digits, all live register/component counts, both decimal signs, octal CYL edits, fifth-character overflow, positive/negative and both zero CLPASS classes, TP debris, raw L normalization, blocked counts and all retained erasable banks.
