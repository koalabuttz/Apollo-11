# Native simulated gyro-output transport

`imu_gyro_device_step` binds the original gyro command counter047 and channel14 to explicit native device state and an output-event buffer. It uses ordinary arithmetic for the selected pulse count, direction/axis bits, divider phase and simulated output payloads. There is no instruction decoder, scheduler, hidden persistent state or copied AGC instruction implementation. Device pending/selection/phase remain external caller-owned state; the canonical image and channels remain authoritative.

Two separately selected transport modes are qualified against the unmodified Virtual AGC peripheral reference. Timed mode consumes one positive counter unit on each divider crossing, clears activity when the counter reaches zero, and publishes pending counts/selection changes in channel0177 payload form. Burst mode retains the reference backend's early counter acceptance, flushing of prior commands and bounded output chunks; this is a simulated transport approximation. The native mathematical divider is6/160 per eligible reference-peripheral step (nominal3200pps); burst aggregation uses its original128000 divider and1024-unit output chunks. The API does not equate an eligible source step with one C64 CPU cycle or establish wall-clock timing. The runtime clock source is a separate caller responsibility.

The reference is deliberately a peripheral-only observation. The host-only GPL tool includes the unchanged engine to reset its file-private device globals per case. A single invocation starts the unchanged mission IMUBAD CAF ZERO instruction, whose two-cycle pending delay prevents any canonical CPU write. The tool asserts the pending flag and unchanged PC, and compares the complete canonical image, source IRQ/SUPER/channels, explicit device state and all18 event-buffer words. No instruction is injected or modified; both original ropes remain unchanged. The default backend and its documented `GYRO_TIMING_SIMULATED` alternative are compiled independently. This does not prove instruction-by-instruction application/peripheral timing.

All262144 states (both missions, both modes,65536 cases each) match the source peripheral reference, strict native and complete ASAN/UBSAN streams. A final reference run also observes actual incoming IRQ0/1 rather than overriding it; every decoded byte remains identical. Inputs retain a complete ordinary positive command-counter sweep, varied old pending counts, all gyro-selection/activity words used by the constructor, phase edges/crossings, and poisoned unowned canonical data. The stated cohort is not an exhaustive Cartesian device-state test.

The nonnull/distinct caller objects and event buffer, ordinary channel14, positive command0..037777, valid mode-specific pending/phase/selection and excluded producers are explicit preconditions. Timed states have phase<160 and pending<800; burst states have phase<128000 and pending<=037777. The18-word output buffer conservatively bounds all flush/publication events in that domain; the corpus observes event counts0..10 in burst and0..1 timed. Event words beyond the returned count remain unchanged. Six invalid mode/counter/phase/selection/channel/pending cases per context verify full image/I/O/device/event/count preservation on rejection.

Four actual PAL C64 PRGs pass128 source-only frozen full peripheral states and24 rejection invariants. All allocations stay below$C000 with compiler ZP0 and checked stack guards. Maximum PRG9135bytes, measured hardware20/software180bytes. Complete original/strict/sanitized streams are retained once per context as deterministic XZ with decoded identity. The GPL engine remains solely a host oracle dependency; no engine code is linked into native C64 diagnostics.

This qualifies simulated gyro counter/output-event behavior. It does not claim physical IMU hardware, real pulse delivery, a runtime clock driver, active augmentation instruction/peripheral composition or complete gyro/application execution. Existing frozen quiescent-producer task/lead-in contracts remain unchanged. The packet adds no containing AGC source-file completion credit; it closes an explicit peripheral binding requirement.
