# Comanche 055 phase maintenance

The MIT `cm_phase` translates the actual CM PHASCHNG and 2PHSCHNG inline-word protocols into a transient native view. Six phase/complement records, stored variable addresses/priorities, time bases, LONGBASE, source scratch and raw register/bank state remain source-addressed data. This module does not execute restart-selected jobs.

Comanche's maintenance algorithm matches the corresponding LM algorithm after checking both original source files, but its fixed entry and return debris differ. CM entries are 05412 and 05372; LONGBASE is 01135; the final DTCB return leaves A=02537 and L=020003. Caller Q, physical bank restoration, SUPERBNK and interrupt enable are preserved exactly. No LM addresses are substituted.

The host-only GPL yaAGC oracle executes the original repository source through the actual banked maintenance routine and BANKCALL return. Independent inputs exhaust all 32,768 raw phase words for PHASCHNG and all 16,384 permitted Type A first words for 2PHSCHNG: 49,152 cases, all 56 modeled words exact. Nine unrelated erasable guards and the inline input words remain intact. The complete source snapshot SHA256 is `88c1b5251014fd53c614140fa83c4043b9e95f6684312ebcfb35856ae9f7052c`.

The shared fixture preparation tool is `tools/cm_services_prepare_reference.py`. It overlays byte-identical original CM service files onto Virtual AGC commit `1b5d6474841a7ab53237ead070f76f35f162f68d`, records explicit pseudo-label indentation patches, and independently assembles the pinned corrected source. Complete ropes must match SHA256 `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`. PHASE_TABLE_MAINTENANCE requires no repair; its original SHA256 is `6f7fb5f01f38d0162c481cb4180173c360f467b2c2f75c080f3675ed8c9e1966`. Historical files are untouched; native code contains no AGC instruction decoder.

Host and ASan/UBSan tests pass 128 frozen full source states and 8,192 invalid group encodings, including no-mutation rejection. Stock PAL C64 compares all 56 words for the same 128 full source states: mailbox `a500008038`, PRG 23066 bytes, text 8614, rodata 14438, BSS 129, final noinit end `$62e8`. Measured sentinel extents are 10 hardware-stack and 13 software-stack bytes, with no extra zero-page spill sections. These measurements cover this bounded diagnostic, not the complete application.

Reproduce with `make cm-phase-differential`, `python3 tools/cm_freeze_phase.py`, `make test-cm-phase sanitize-cm-phase c64-cm-phase`, then `python3 tools/cm_phase_vice_test.py --vice /path/to/x64sc --rom-dir /path/to/C64 --data-dir /path/to/vice`. Until integrated, add `-f Makefile -f tools/cm_phase.mk`. Preparation is `python3 tools/cm_services_prepare_reference.py`. Evidence and SHA256 lists are `evidence/cm-phase-*` and `evidence/cm-services-*`.
