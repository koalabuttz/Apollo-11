## Runtime REU bound check

Each run below is a `tools/flight_scenario_vice.py` flight run on the C64 in VICE (stock C64, 2 MB REU). Two checks per run: every REU byte that changed lies in a writable region (the image before the run against the one VICE wrote back), and every DMA the run made, read or write, lies inside one declared region (a VICE monitor trace on each $DF01 command). Either one failing fails the run. VICE now and then evaluates the trace only after a DMA has run; for those (column "seen late") only the last byte is range-checked, and their writes are still in the byte compare.
