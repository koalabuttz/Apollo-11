# Luminary099: recovery and restart tests

Generated by `tools/restart_acceptance.py lm` at commit `11cab8d39055`. Result: **PASS**

Flight store image: `flight-store/lm.reu` sha256 `d905808ec3ae8d6c144fc43c1c8d45f086031e0d549642fa7332259e3516f1c1`

This is the `recovery_and_restart_tests` evidence of the `integrated_applications.Luminary099` entry (docs/PORT_SCOPE.md). Each row is a hardware restart (GOJAM) in flight. On the host (tools/flight_restart_check.py) the restart and the resumed program run in lockstep with yaAGC to the row's end (an unscaled row is sampled against a free-running yaAGC, and names any sample the restart adds that differs), and the program ends in the same major mode as the run without the restart.

On the C64 (tools/flight_scenario_vice.py --replay --replay-exact --strict-start, VICE, a stock C64 with the store in an REU) the window starts at the host's GOJAM point, just after the GOJAM, so it replays the recovery: 300 cs with the host's inputs, a checkpoint every 50 cs. At each checkpoint the C64 must equal the host in erasable 0000-3777 (less the clock scalers 0024-0031 and RUPTREG1-4, 0070-0073), the timers and the output channels, with no compare skipped, and every REU DMA must stay inside the program's layout (tools/reu_layout.py). The window covers the recovery, not the whole resumed phase, which the host covers to the row's end. For the rows GOJAM_ON_C64 names, the GOJAM is also applied on the C64 itself (the GOJAM module, then the restart burst against yaAGC). Speed is not a criterion. So the chain is: the host matches yaAGC, and the C64 matches the host.

The inputs (keys, loads, radar and vehicle models) are each scenario's, in tools/flight_host_differential.py (FLIGHT, RESTART_POINTS) and tools/flight_restart_check.py (RESTARTS).

Known gap: the night watchman (a job that loops without the Executive, such as GOTO on an erasable CADR cycle) restarts the AGC on the host and the x86 program (lm-p52-watchman, docs/FLIGHT-RESTART.md, The night watchman), but not yet on the C64, which hangs at that point instead. Nominal flight never trips it, and no row here uses it.
