# Canonical Comanche ENEMA

`cm_enema_image` executes original ENEMA05,2651 using the sole2048-word canonical
image and explicit `cm_native_io`. It gathers the released Executive, Waitlist,
restart, phase and CPU views, calls the source-qualified ENEMA body, and commits
its actual effects. Phase records are read-only. The returned image contains
the actual selected MMDSPLAY05360, PTBAD02746 or DOFSTART02365 entry; subsequent
application bodies remain separate compiled groups.

A fresh byte-original-layout rope (`6e3150ae9b43535237e10f565205d1f65e6d60cafbe8935be598e03e9810b061`)
independently executes all4096 input cases. Every state compares all2048 physical
words (A/L/Q retain raw16-bit registers), all13 explicit CM I/O/metadata fields,
and the selected result. The retained complete stream SHA256 is
`cf5e45baa06b836b97f38a957ad4275cf5857b36136344a1803767d57af61dfb`.
Strict host and full ASAN/UBSAN runs match that stream. The cases cover fresh,
ordinary, TVC WAITLIST and bad-phase outcomes, all entry erasable banks and
qualified SUPER/IRQ/raw-register cohorts. They retain the underlying helper's
legal phase, paused counter and available WAITLIST domain; this packet does
not certify arbitrary scheduler corruption or an entire initialization file.

Stock PAL C64 executes32 representative contexts through actual disk overlays
219/254/255, compares complete-state fingerprints at all32 boundaries, two
whole2061-field image/I/O samples, and the final2048-word image externally.
Mailbox `a500002000` records success. Software stack extent is1112 bytes,
including the diagnostic input constructor and resident transport. Native219
loads7028 bytes; its transient934-byte view cache occupies overlay BSS
`$9b74..$9f15`, below `$c000`. The loader resets this BSS on load, and every
invocation regathers every view before use. It contains no authoritative
persistent flight state. Source producers must remain excluded and the service
must not be entered recursively while these transient views are active.

The first automatic-frame target attempt failed its resident return even though
its full original-source case0 output image matched exactly. The retained
failed PRG can be reproduced byte-for-byte from the automatic-frame variant.
Its MOS epilogue computes the restored software-stack high byte, then loads
return status over that value before storing the stack pointer. Disassembly,
failed mailbox `a501000000`, source/map/PRG/D64/captures, and reconstruction are
retained in `evidence/cm-enema-image-first-target-failure/`. Moving MOS-only
views to reset-on-load BSS avoids that toolchain trigger; the host implementation
continues to use automatic views. This is a target storage workaround, with no
source-state normalization or change to historical helpers.

Run `make -f Makefile -f tools/cm_enema_image.mk test-cm-enema-image` and
`sanitize-cm-enema-image`; use `cm_freeze_enema_image.py`,
`cm_enema_image_build.py` and `cm_enema_image_vice_test.py` for target replay.
Native code is MIT C with no AGC decoder. The original engine is host-only GPL
oracle code. Released older ENEMA artifacts and their rope identity remain
unchanged; this additive packet qualifies the original-layout canonical bridge.
