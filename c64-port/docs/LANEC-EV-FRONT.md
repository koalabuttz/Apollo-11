# EXTENDED_VERBS front end

Lane C. Milestone `lanec-ev-front`.

## Scope

`Luminary099/EXTENDED_VERBS.agc` lines 40-158 and `Comanche055/EXTENDED_VERBS.agc`
lines 41-148, both assembled in bank 43 at the same addresses (02000-02127 LM,
02000-02123 CM): the fan-out, the extended-verb display grab and release, and
the operator-error exits. Every other label in both files (the verb bodies the
fan selects) is still untranslated, so both files move from `untranslated`
to `partial` in `docs/port-coverage.json`.

Each native entry runs one source path from its entry to the first boundary,
a transfer to code that another routine, file or lane owns, and leaves the
image exactly as the original program leaves it there: A/L/Q debris, the
stores, Z at the boundary, FB/BB and superbank. Boundaries are callee
entries (FALTON, NVSUB, POSTJUMP, ENDEXT, TCQ), a selected verb body, or the
caller's own return.

## Source map

| Source | Native | Boundary |
|---|---|---|
| GOEXTVB `INDEX MPAC`, `TC LST2FAN` | `lanec_ev_goextvb` | |
| LST2FAN, 60 `TC`/`TCF` slots | `lanec_ev_goextvb`, slot table generated by name from the listing (`LANEC_*_LST2FAN_TABLE`) | selected verb entry; VERB69 stops at its own slot (its body is the hardware-restart trap, separate) |
| TESTXACT (all four CCS outcomes of EXTVBACT and of the masked FLAGWRD4) | `lanec_ev_testxact` | FALTON via ALM/END, or NVSUB |
| SETXTACT (TS overflow skips on both stores) | `lanec_ev_setxtact` | NVSUB |
| XACT0 | `lanec_ev_xact0` | NVSUB |
| SETXTACT +5 / +6 (NVSUB's busy and normal returns), `TC MPAC +1` | `lanec_ev_setxtact_return` | the caller return SETXTACT saved, with Q = MPAC +2 |
| XACTALM, and XACTALM +1 (FALTON returns) | `lanec_ev_xactalm` | FALTON; ENDEXT |
| ALM/END, and GOPIN (FALTON returns) | `lanec_ev_alm_end` | FALTON; POSTJUMP with CADR PINBRNCH |
| CHKPOOH (LM only) | `lanec_ev_chkpooh` | TCQ for P00/P00-, else FALTON via ALM/END |
| OC24100, TERMEXTV, ENDEXTVB | constants/equates used by the above | |
| dispatch by Z | `lanec_ev_front_dispatch` | |

`TC MPAC +1` executes the word SETXTACT stored there, which is the caller's Q,
a TC to fixed memory. The native routine performs that transfer for saved
words in 02000-07777 and rejects anything else as out of scope.

## Harness

`tools/lanec/` is shared by Lane C milestones:

- `symbols.py` generates `include/lanec_symbols.h` (addresses and transfer
  tables, by label name) from the pinned fixture listings, after checking the
  fixture copies of all Lane C files against the originals. The only accepted
  differences are recorded in the script: transcriber `SBANK=` workarounds,
  the DSPOCTWO/DSPOCTWD spelling, a duplicate PRIOSAVE equate, CAF/CA on
  erasable and `+8`/`+8D`.
- A suite (`tests/lanec_<name>_cases.c`) generates cases: a random but
  well-formed image, the entry, the varied inputs and the exact address
  ranges the native code translates.
- `oracle.c` runs the original rope in Virtual AGC from the entry until
  control leaves those ranges or reaches a label owned elsewhere.
  `native.c` runs the native dispatcher on the same case. `diff.py` requires
  every line to be identical.
- `freeze.py` stores oracle CRC-32s for a subset; `c64_diag.c` recomputes the
  native results on the C64 and compares them.
