# Translate Comanche055 P34-35_P74-75

Lane E (targeting). Milestone `cm-p34-p35`. How the routines are made and checked: `docs/INTERP-COMPILE.md`.

`Comanche055/P34-35_P74-75.agc` (`src/cm_p34_p35.c`) is native C in full. All 1,065 words, across banks 02, 04, 11, 20, 22, 35, 36 and 40-42, are compiled by `tools/interp_compile.py` into 513 routines of the control-transfer ABI. The spec is `cm-p34-p35` in `tools/interp_specs.py`.

The file holds:
- P34/P74 (TPI) and P35/P75 (TPM), S33/34.1 and S34/35.1 through S34/35.5;
- LOMAT, INTINT, VN1645, KILCLOCK, N45PROC, CLUPDATE and DISPLAYE;
- P3XORP7X, INITVEL, MIDGIM, GET+MGA, MIDGIM1 and GET.LVC;
- SELECTMU, PERIAPO1, PERIAPO, PRECSET, LEMSTORE, CSMSTORE, VECSHIFT, SHIFTR1, R36 and LREGCHK;
- VNPOOH (bank 02, fixed-fixed).

## VNPOOH

VNPOOH (14 words, fixed-fixed bank 02) switches FBANK itself: `XCH FBANK` puts VNBANK's word (`TC -5`, FB 02) in FB and saves the caller's FB in TBASE5, the display runs through `BANKCALL`/`GOFLASH`, and `TS FBANK` puts TBASE5 back before `TC RTRN` returns to the caller. The compiler now lets basic code write FBANK with `XCH` or `TS` when the instruction is in fixed-fixed memory, where a new FB leaves the code where it is (`ai_put` keeps BBANK with it).

VNPOOH's way back (VNBANK -1 on proceed, VNBANK +1 after a recycle) runs `TC RTRN` under TBASE5. Its cases start with TBASE5 at FB 35 and RTRN (1767 under the case's EB) at one of this file's five VNPOOH returns, as a call from the file leaves them. With a random RTRN, `TC RTRN` would land in the middle of other code, where the native run stops at the jump and the original runs on. A call from another file (P30_P37, P32-P33_P72-P73, TPI_SEARCH) leaves its own return and FB there, and the same `TC RTRN` takes it out of this file.

## Compiler and spec additions

- **RTB DPMODE.** `src/rtb_modes.c` gives DPMODE a native body, `rtb_dpmode`, guarded like `rtb_angles`. SGNAGREE is a stop.
- **CLR** compiles like CLEAR.
- **TLOAD of a fixed constant** reads three words with `cmi_tload_fixed`.
- **`outside`** left VNPOOH out of the routines until the FBANK writes above compiled; the spec no longer uses it.
- **Superbank CADRs in a mixed file.** A CADR maps to bank 40+ only when the routine using it is in bank 40 or above, so the bank 35 code's CADRs stay in bank 35.
- **Z reads.** A basic instruction that reads Z (`CA Z`) sees the address after it.
- **Skip returns.** The oracle (`tools/interp_routine_reference.c`) also stops at the case's return plus one, so P3XORP7X's `INCR Q, RETURN` ends like a plain return.
- **States.** MUTABLE is read with X1 = -2 or -10 (`fixed_index`). SETMUER's VAC+46 is the earth or moon index.

## Evidence

Hashes: `evidence/cm-p34-p35/SHA256.json`. Bulk files are assets of the `evidence-cm-p34-p35` release.

- **Source map.** `cm-p34-p35-source-map.json` lists every word with the routine that compiles it.
- **Independent assembly comparison.** `make cm-p34-p35-differential` runs 512 states per routine (262,656 cases). All equal yaAGC in Z, all 2,048 erasable words and the interrupt-enable state. Every 512th case is frozen in `tests/cm_p34_p35_vectors.h`.
- **Host and sanitizer results.** `make test-cm-p34-p35 sanitize-cm-p34-p35` runs the frozen cases (`cm-p34-p35-host.log`).
- **C64 execution results.** `make vice-cm-p34-p35` runs 47 diagnostics with 584 cases, 11 of them truncated (`cm-p34-p35-vice.log`). Every routine runs on the C64; none is host only.
