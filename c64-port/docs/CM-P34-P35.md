# Translate Comanche055 P34-35_P74-75

Lane E (targeting). Milestone `cm-p34-p35`. How the routines are made and checked: `docs/INTERP-COMPILE.md`.

`Comanche055/P34-35_P74-75.agc` (`src/cm_p34_p35.c`) is native C except for VNPOOH. Of its 1,065 words, across 10 banks, 1,051 are compiled by `tools/interp_compile.py` into 185 routines of the control-transfer ABI. The spec is `cm-p34-p35` in `tools/interp_specs.py`.

The file holds:
- P34/P74 (TPI) and P35/P75 (TPM), S33/34.1 and S34/35.1 through S34/35.5;
- LOMAT, INTINT, VN1645, KILCLOCK, N45PROC, CLUPDATE and DISPLAYE;
- P3XORP7X, INITVEL, MIDGIM, GET+MGA, MIDGIM1 and GET.LVC;
- SELECTMU, PERIAPO1, PERIAPO, PRECSET, LEMSTORE, CSMSTORE, VECSHIFT, SHIFTR1, R36 and LREGCHK.

## Not translated

VNPOOH (14 words, bank 02) switches FBANK itself with `XCH FBANK` and `TS FBANK`, which the compiled basic code does not model yet. The spec's `outside` key leaves it out, and the file stays `partial` until it is translated.

## Compiler and spec additions

- **RTB DPMODE.** `src/rtb_modes.c` gives DPMODE a native body, `rtb_dpmode`, guarded like `rtb_angles`. SGNAGREE is a stop.
- **CLR** compiles like CLEAR.
- **TLOAD of a fixed constant** reads three words with `cmi_tload_fixed`.
- **`outside`** leaves named words out of a file's routines.
- **Superbank CADRs in a mixed file.** A CADR maps to bank 40+ only when the routine using it is in bank 40 or above, so the bank 35 code's CADRs stay in bank 35.
- **Z reads.** A basic instruction that reads Z (`CA Z`) sees the address after it.
- **Skip returns.** The oracle (`tools/interp_routine_reference.c`) also stops at the case's return plus one, so P3XORP7X's `INCR Q, RETURN` ends like a plain return.
- **States.** MUTABLE is read with X1 = -2 or -10 (`fixed_index`). SETMUER's VAC+46 is the earth or moon index.

## Evidence

Hashes: `evidence/cm-p34-p35/SHA256.json`. Bulk files are assets of the `evidence-cm-p34-p35` release.

- **Source map.** `cm-p34-p35-source-map.json` lists every word with the routine that compiles it, or why it is untranslated.
- **Independent assembly comparison.** `make cm-p34-p35-differential` runs 512 states per routine (94,720 cases). All equal yaAGC in Z, all 2,048 erasable words and the interrupt-enable state. Every 512th case is frozen in `tests/cm_p34_p35_vectors.h`.
- **Host and sanitizer results.** `make test-cm-p34-p35 sanitize-cm-p34-p35` runs the frozen cases (`cm-p34-p35-host.log`).
- **C64 execution results.** `make vice-cm-p34-p35` runs 22 diagnostics with 358 cases (`cm-p34-p35-vice.log`). Six routines (CM 11,2000, 11,2022, 11,2056, 11,2174, 35,2264 and 35,2567) run too much code for one C64 program and are compared on the host only (`c64_host_only` in the proof).
