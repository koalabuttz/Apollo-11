# Comanche canonical WAITLIST return

`cm_waitlist_image` composes source-qualified insertion with complete original WAITLIST register and scratch effects through its actual DTCB return. A carries the positive bounded delay, Q identifies the actual caller's inline 2CADR, and the source-resolved task pair arrives as compiled metadata. Source TIME3/list cells, WAITEXIT/WAITBANK/WAITADR/WAITTEMP, raw A/L, Q displacement, Z, physical banks and INHINT are exact. The native helper never reads an executable rope. A valid nonfull queue whose discarded item is the original ENDTASK descriptor is a caller obligation; alarm entry paths remain the separately verified bounded WAITLIST milestone.

The 1024 full-image cases include actual original CLOKTASK `(03277:03260,050067)` and TIG-5 `(02576:02612,050066)` inline pairs, plus original dynamic GOLOC data. The independent oracle qualifies the actual caller's fixed bank as well as its PC when detecting return, so a same-numbered WAITLIST internal instruction cannot end the comparison early. Source bank words carry original SUPERBNK metadata; the returned physical BB retains only real bank bits while the external SUPERBNK latch is unchanged.

All 1024 original-source cases compare every 2048 physical erasable word, raw A/L, source Z/Q/banks, external SUPERBNK/IRQ and exit status. Host and ASan/UBSan pass all 1024 frozen full-image fingerprints and two complete 2051-value states. Snapshot SHA256 is `dba29296c26af57eac8cc99c6a96d4939e0342ba62c7ea8244ae50a7952c6f87`. Counter-drive inputs are held zero, source scaler updates are frozen, and no output word is normalized. The GPL oracle runs only on the host, using Virtual AGC `1b5d6474841a7ab53237ead070f76f35f162f68d`; original WAITLIST is byte-preserved except its audited nine indentation-only pseudo-label repairs. The pinned corrected supporting-source domain is documented in `COMANCHE_WAITLIST.md`; rope SHA256 is `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`. Historical originals are untouched.

PAL C64 passes 128 representative complete-image fingerprints and one complete 2051-value state: mailbox `a500008000`, PRG 19226 bytes, text 6892, rodata 12320, BSS 4122, image end `$6333`, hardware/software stack extents 12/83 bytes, no extra zero-page sections. Native code is MIT, owns the sole canonical image, retains no persistent private flight state or suspended overlay frame, and contains no source decoder. Producer exclusion is caller-owned. This standalone proof does not establish whole-application overlay fit or WCET.
