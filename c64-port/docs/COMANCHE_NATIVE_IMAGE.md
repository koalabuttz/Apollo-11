# Comanche canonical flight image

`cm_native_image` gathers and commits source-specific CM views against the existing sole 2048-word / 4096-byte `apollo_overlay_state`. Seven core sets begin at 0154, five VACs at 0400, restart phase pairs at 0752, variable restart addresses at 01436, priorities at 01054 and time bases at 01053; Comanche LONGBASE is 01135. Executive, WAITLIST, restart/interface and phase views contain no persistent second flight image. Absolute source addresses index words directly.

Device channels, key latches, SUPERBNK, interrupt enable, trap latches and native scheduler fault markers are explicit `cm_native_io` metadata outside erasable memory. No source word is invented for them. Raw 16-bit A/L representations survive adapters; committing phase or ENEMA register views synchronizes BBANK, EBANK and FBANK. Executive adapters commit exactly their modeled core/VAC/scheduler words and leave physical register words caller-owned. Source Z is not interpreted as a native instruction counter. This adapter does not execute an AGC instruction stream.

Scratch aliases matter: phase scratch0063/0064 overlaps NEWPRIO/LOCCTR, and WAITLIST shares source scratch addresses with restart/Executive. Commit each source group before returning from an overlay and regather after every dispatcher boundary. Do not commit stale overlapping views. Keep callback/module pointer tables resident and caller-owned; producer exclusion spans composed swaps, which occur only after previous overlay C frames return. The existing loader's module/header/CRC checks remain the disk integrity boundary.

Compile-time bounds establish a 740-byte combined Executive/restart view within the reserved 768-byte `$c100..c3ff` cache and the smaller WAITLIST/phase/I/O views within `$c400..c7ff`. These checks establish adapter view bounds, not the size of an entire application runtime or stack.

Verification reuses the independent source-executed restart/Executive callback corpus: 64 sequences, 320 checkpoints, 192 callbacks. At every operation boundary, views commit to the sole image, are poisoned, then regather before comparison with all 434 source-derived values. Host and ASan/UBSan pass all 320 complete-state fingerprints and eight full samples, plus independent source address-map checks, raw register encodings, bank synchronization, scratch alias observation and 16 untouched image guards. The authoritative source snapshot SHA256 is `0fc55bb17cc785f54a944917685917feff3dee8e3b4af53db10be1b924707de8`; callback fixtures and exact scope are documented in COMANCHE_RESTART_NATIVE.md.

Stock PAL C64 executes the same 64 sequences / 192 callbacks and compares 320 complete-state fingerprints after each poison/regather boundary: mailbox `a500004001`; PRG 29383 bytes, text 27914, rodata 1455, BSS 5008, final noinit end `$8e57`. This standalone diagnostic allocates its image locally; application allocation uses the established `$7000..7fff` image and separate resident caches. Stack sentinel extents are 27 hardware and 275 software bytes, with no extra zero-page sections. These measurements do not establish whole-application fit or WCET.

Reproduce with `make test-cm-native-image sanitize-cm-native-image c64-cm-native-image` and `python3 tools/cm_native_image_vice_test.py --vice /path/to/x64sc --rom-dir /path/to/C64 --data-dir /path/to/vice`. Before integration, add `-f Makefile -f tools/cm_native_image.mk`. Evidence/hashes are `evidence/cm-native-image-*`; the original source corpus remains in `evidence/cm-restart-native-*`.
