# Original LM/CM Pinball sleep admission

`dsky_nv_busy` implements original ENDIDLE, NVSUBUSY, PRENVBSY, NVSBWAIT and internal NVSUBSY1 through the actual selected JOBSLEEP, POODOO or NVSBCOM entry. It retains canonical register/bank/scratch effects, the source CADRSTOR/DSPLIST writes and channel-11 KEY REL light. The following scheduler, alarm or admission body is a separate service. Both missions use their actual source addresses and POSTJUMP destination; no AGC instruction is decoded.

The canonical image is authoritative, with SUPER/IRQ in `p66_bias_io` and channel11 explicit. Producers must be excluded by the caller. The supported caller Q is 02000..03777, input A is sign-agreed, banks are coherent, scratch/flags ordinary, and DSPLOCK 0..7 for NVSBWAIT. Internal NVSUBSY1 requires bank04. The source DSPLIST negative-zero case skips into inline alarm data and is deliberately excluded; CADRSTOR negative zero instead falls through into ISLIST and is reproduced exactly. Unsupported contexts preserve the complete image, IO, channel and route. No scheduler poll is added.

Strict native and full ASAN/UBSAN output agree with all 10,240 complete original-source states, each retaining every erasable word, SUPER/IRQ/channel11 and selected route. Raw SHA256: `bb82322090522e0a3930ee9d2d94696c167fbfaa50964e06fd8596e8be8d7bd8`. The corpus covers five entries in both missions, both signed CADRSTOR zeros, nonzero positive/negative occupied markers, available and blocked NVSBWAIT, every EB/FB/SUPER class, both interrupt states and varied preserved memory.

The frozen checker covers 80 complete states and 120 unchanged invalid guards. Actual PAL C64 in VICE passes all 80 states: mailbox `a500005000`, PRG 5,672 bytes, hardware stack 14 bytes including 14 ROM bytes, software stack 35 bytes, no added zero-page allocation. The source/sanitizer streams are retained compressed; exact identities appear in `evidence/dsky-nv-busy-proof.json`. `tools/dsky_nv_busy.mk` provides full-route `all`, frozen `test`, complete-stream `sanitize`, and target builds. This is bounded admission proof, not a whole Pinball or scheduler certificate. GPL source-engine comparison is host-only; the native implementation is MIT integer C.
