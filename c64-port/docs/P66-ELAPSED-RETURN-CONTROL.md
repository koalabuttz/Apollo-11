# Elapsed subtraction return register

The literal DSU entry at `00,7005` reaches ENDVXV's double addition. When its initial accumulator overflow indicator is zero, the BZF to DANZIG preserves the incoming Q. An initial overflow calls OVERFLOW through SETOVF and leaves Q=3, including both later TS skip paths. The released uninterrupted P66 fixture had Q=3 here; a job that actually ran and returned may leave another value.

The additive `p66_elapsed_return_q` observes the initial double addition using the existing source-qualified primitive. It neither reruns overflow realignment nor changes any numerical result. `p66_elapsed_return_control` commits only Q at the actual completed elapsed boundary: PC06061, LOC03360, MODE0, EDOP0, FB064000, EB01000, BB064002. Invalid control states, nonordinary source operands and null images return2 before mutation. The caller retains the input MPAC/PIPTIME pair and Q across the ordinary C call and owns producer exclusion.

All8,192 independent unchanged-assembly cases match every2,048 canonical word plus SUPER and source interrupt metadata. The corpus combines all256 signed-zero/high-low corner combinations with eight incoming Q values, including the actual higher-priority job return02701, and6,144 random operand cases. Strict and full ASAN/UBSAN streams match decoded SHA65eb3ca920095de18784edfa16ab46727a1dbe1ddf3e33bcb2d1640847de90a6. Twelve invalid domains and a null image retain all canonical words.

The stock-ROM C64 diagnostic checks64 frozen original-source Q records covering eight incoming Q values, signed zero and both initial overflow signs. Every call checks all2,048 canonical words, allowing only the qualified Q change. The target mailbox is a50000400002; measured software/hardware stack extents are3/12bytes, with zero additional zero page. This target proof covers the control observer; complete numerical DSU states are separately compared against original assembly on the host and in the released numerical milestone.

Build and verify with `tools/elapsed_return_control.mk`. `tools/elapsed_return_control_target_build.py` derives fixed target inputs and expected Q only from the retained original-source archive; the target contains no test-input constructor or AGC decoder. The frozen elapsed arithmetic, previous return controls, native dispatcher, application and recurrence sources remain unchanged. Generic scheduling and other DSU callers are outside this bounded adapter.
