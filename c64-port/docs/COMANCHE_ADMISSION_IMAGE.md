# Comanche canonical NOVAC/FINDVAC return

`cm_admission_image` composes the independently source-qualified seven-core Executive admission with the actual Comanche NOVAC/FINDVAC caller return. The sole canonical image retains every physical source word, including EXECTEM1/2, raw A/L, actual Q=06712 after the fixed Q+2 helper, caller Z and restored banks. The source-resolved job 2CADR arrives as compiled metadata. SUPERBNK remains unchanged and INHINT leaves IRQ disabled. Successful ordinary positive-priority admission requires an available core and, for FINDVAC, an available VAC; resource alarm image prefixes remain outside this wrapper's scope.

All 1024 cases compare every 2048 physical word plus external SUPERBNK/IRQ and status against original assembly: 512 FINDVAC and 512 NOVAC, all seven core positions, all five VAC positions, all eight erasable and 32 fixed banks, and actual CLOCKJOB/DYNDISP/S40.13/NBDONLY/SETJTAG source pairs. Host and ASan/UBSan pass all fingerprints and two complete 2051-value states. Snapshot SHA256 is `47268d6b996f2e21105eaaa0490b61d83ba2bae289ce581fcee5965f22d83ec5`. Counter-drive inputs are zero, the source scaler is frozen, and no output is normalized. The host-only GPL oracle executes Virtual AGC `1b5d6474841a7ab53237ead070f76f35f162f68d`, byte-preserved original Executive with its five audited indentation-only repairs and pinned corrected supporting sources. Fixture rope SHA256 is `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`; historical originals are untouched.

PAL C64 passes 128 representative whole-image fingerprints and one complete 2051-value sample, mailbox `a500008000`. PRG 19180 bytes, text 6842, rodata 12324, BSS 4122, image end `$6305`, hardware/software stack extents 14/667 bytes, no additional zero-page sections. Native code is MIT and retains no persistent flight-image duplicate, rope decoder or suspended overlay frame. Caller-owned producer exclusion spans each service. This standalone diagnostic does not establish whole-application fit or WCET.
