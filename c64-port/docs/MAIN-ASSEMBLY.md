# MAIN.agc as a native manifest

Lane A. Milestone `main-assembly`. Covers `Luminary099/MAIN.agc` and `Comanche055/MAIN.agc`.

MAIN.agc holds no instruction, constant or declaration. It is the program's include list: one `$` line for each source file, in assembly order. The assembler reads the files in that order, and the order decides where each file's words land in the rope.

The native form is `src/main_manifest.c` (`include/main_manifest.h`), generated by `tools/main_assembly.py` from yaYUL's listing. For each mission it holds:
- every include, in order, under the name MAIN.agc gives it;
- the runs of fixed words each file emits;
- each file's word count and sum;
- the 36 bank checksum words, which the assembler writes itself.

`main_manifest_check()` (`tests/main_manifest_check.c`) checks a mission's manifest against the rope. It checks each file's word count and sum, and that no word is emitted twice. Every word no file emits must be unused (+0, or TC to itself, the assembler's fill) or a bank checksum.

## What the tool checks

`python3 tools/main_assembly.py` checks, for each mission:
- **Every include names a checked-in file.** Every other checked-in `.agc` file is included exactly once. Two Luminary099 lines name files the scan saved under other names:
  - `LAMBERT_AIMPOINT_GUIDANCE.agc` is the checked-in `GENERAL_LAMBERT_AIMPOINT_GUIDANCE.agc`. The pinned Virtual AGC MAIN.agc includes `LAMBERT_AIMPOINT_GUIDANCE.agc` too.
  - `TRIM_GIMBAL_CNTROL_SYSTEM.agc` (sic) is `TRIM_GIMBAL_CONTROL_SYSTEM.agc`, which is also the pinned MAIN's spelling.
- **Same files, same order.** The pinned MAIN.agc that yaYUL assembles into the oracle rope (`build/fixed-data/<mission>/MAIN.agc`) includes the same files in the same order. It uses its own names for some of them (`ALIAS` in the tool: punctuation, and names such as `STABLE_ORBIT_-_P38-P39.agc`).
- **Every word has one owner.** In yaYUL's listing, MAIN.agc emits no word. Every emitted fixed word is attributed to exactly one include and equals the rope. The 36 bank checksums are the only other words that are not fill.

`--check` fails when `src/main_manifest.c` is not what the listings give (`make main-assembly-differential`).

## Evidence

Hashes: `evidence/main-assembly/SHA256.json`.
- **Source map.** `evidence/main-assembly/main-assembly-source-map.json` (`tools/main_assembly.py`) lists, per mission and in order, each include, its checked-in file, the assembler's name for it, its runs, word count, banks and sum.
- **Independent assembly comparison.** `evidence/main-assembly/main-assembly-proof.json` (`make main-assembly-differential`, `tools/main_manifest_reference.c`, host-only) uses yaAGC's own rope loader (bank order and parity). It compares each file of the native manifest with the words yaAGC holds at its runs. It also runs yaAGC from each unused TC-to-itself word in banks 0-37, which must loop. Luminary099: 89 files, 57 fill loops. Comanche055: 84 files, 52 fill loops. 0 differing.
- **Host and sanitizer results.** `make test-main-assembly sanitize-main-assembly`: both manifests against both ropes, 177 checks, 0 failures.
- **C64 execution results.** `make vice-main-assembly` (`platform/c64/main_manifest_diagnostic.c`) runs the same check of both manifests on the C64, against the ropes the self-check program already keeps in the REU (`build/self-check.reu`, `include/rope_image.h`): 177 checks, 0 failures. The C64 runs the whole check, every file and every word, so there are no rows to pick.
