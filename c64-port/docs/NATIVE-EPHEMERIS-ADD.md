# Original ephemerides triple-add arithmetic prerequisite

Both original ephemerides programs use interpreter TAD to accumulate their launch/time offsets. `ephemeris_triple_add` translates that basic routine and its actual overflow return into native C. It reads the lower two operand words before DAS and rereads the major word afterward, preserving source scratch aliases. Both OVERFLOW exits execute literal TC Q, leaving Q=3; no-overflow paths preserve incoming Q. The native call stops before original DANZIG executes the following interpreted pair.

The contract requires exclusive ownership of the canonical 2,048-word image, ordinary erasable triples selected by ADDRWD, coherent EB/FB/BB, ordinary non-CPU words, raw A/L and REGZERO +0. No device, interrupt, SUPER or producer operation runs within the call. Unsupported inputs preserve the entire image. Twelve selected operand bases include actual MPAC/BUF/OVFIND aliases and banked end-of-bank triples. The 131,072 original states exercise both missions, every incoming 16-bit A and L pattern individually, both interrupt states and all SUPER selections with signed-zero, limit, overflow and seeded raw data. This is a sampled multidimensional cohort, not an exhaustive Cartesian-domain proof.

All original, strict native and full ASAN/UBSAN 2,053-word records agree, with one retained original archive per mission. The lossless 72-state target fixture checks every physical word and its external latch observations on stock-ROM PAL C64, plus 13 complete-image rejection guards and a null guard. Its mailbox is `a5480000`; PRG size9,160 bytes, BSS end `$4bc7`, measured stacks hardware8/software76 bytes, additional zero page0. This is a standalone component check; no production overlay allocation is claimed.

The first target passed all72 original states and then failed a diagnostic guard which set BBANK to0, identical to the valid input. The corrected guard sets incoherent BBANK to1. The unchanged arithmetic, failed PRG/map/mailbox/logs and original guard source are retained in `evidence/ephemeris-add-first-target-guard-failure/` with an explicit cause record.

`ephemeris_source.py` independently assembles both unchanged ephemerides files, audits all74 LM and71 CM emitted words, and verifies the original ropes. For interpreter dependencies it uses the separately audited historical-line-aligned fixtures and disclosed indentation repairs; each mission's29 TAD/overflow words maps to the unchanged rope. The complete source inventory does not grant executable credit to the ephemerides programs: their time preparation, lunar/solar vector algorithms and caller control remain to be translated. INTERPRETER also remains partial.
