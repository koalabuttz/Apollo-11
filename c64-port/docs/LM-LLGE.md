# Translate Luminary LUNAR_LANDING_GUIDANCE_EQUATIONS

Lane F (LM powered flight and DAP). Milestone `lm-llge`. How the routines are made and checked: `docs/INTERP-COMPILE.md`.

`Luminary099/LUNAR_LANDING_GUIDANCE_EQUATIONS.agc` (`src/lm_llge.c`, generated by `tools/interp_compile.py lm-llge`) is native C on the control-transfer ABI except the 15 words that read or write I/O channels. The file is the landing guidance of P63 to P67: the guidance pass the SERVICER reaches through AVEGEXIT (LUNLAND, ?GUIDSUB and GUIDSUB with the phase tables NEWPHASE to WHATALM), the P64 redesignation (REDESIG, REDESMON and its counter in PITFALL's bank), the time-to-go and target logic (TTFINCR, TTF/8CL with the ROOTPSRS polynomial root finder, QUADGUID, CGCALC and the EXTLOGIC phase switch), the P65 to P67 starts and the rate-of-descent task (STARTP66, STARTP67, RODTASK, RODCOMP, VHORCOMP), the guidance displays (P63DISPS, P64DISPS, VERTDISP, TDISPSET) and FASTCHNG.

258 routines start at the entries (LUNLAND, ?GUIDSUB, GUILDEN, PITFALL, DESCBITS, P63DISPS -2, INTPRETX, ROOTPSRS, FASTCHNG, RODTASK, STARTP66, STARTP67, P65START, STARTP64, REDESMON), at every point another file returns to, at words nothing in the file reaches (`resume_orphans`), and at every word after a DANZIG (`resume_keys`): the guidance runs as a job, so a DANZIG can find a job waiting and stop at CHANG2, and the Executive resumes the job there. `RTB LOADTIME` is native (`src/rtb_angles.c`), and `RTB NORMUNIT` is too (`src/lm_normunit.c`, the NORM front of `src/rtb_vector.c` and UNIT's phases of `src/rtb_unit.c`).

Not translated: the 15 words (with their `EXTEND`s) of `READ CHAN30` (STERN, in GUILDEN), `RAND`/`READ CHAN31` (the mode-control and hand-controller checks in STABL?, RATESTOP, PITFALL, REDESMON and its counting loop) and `WOR CHAN13` (STARTP64). They wait for an I/O channel model in the control-transfer ABI. The compiled routines stop with `EXEC_OUT_OF_SCOPE` at them, and the source map records them as untranslated with that reason. The file stays partial until they are translated, and the earlier P66 work in `docs/port-coverage.json` stays listed beside this one.

## Compiler changes

`tools/interp_compile.py` gained `index_tcf`, `basic_fixed_index`, `index_erasable`, `intpret_via`, `in_file_returns`, `returns` 0, `rtb` stop codes, `TC A`, `INCR BBANK` and `index_carry16` (listed in `docs/INTERP-COMPILE.md`). Every other spec still regenerates byte-identical (`--check`). `cm-p34-p35` differs with the base compiler too, so that is not from this change.

`index_carry16` fixes a C64-only fault in the generated `ixw()` (INDEX K): its end-around carry tested bit 16 of an `unsigned`, which is 16 bits on the 6502. There, `INDEX WCHPHASE` with WCHPHASE -1 lands one word low, and the indexed TCF table refuses. The host builds were right, so only the C64 diagnostic showed it. Other specs keep the old form until the steward decides on a shared regeneration.

## Evidence

Hashes: `evidence/lm-llge/SHA256.json`.

- **Source map.** `lm-llge-source-map.json` lists all 991 words with the routine that compiles each, or the reason it is not compiled (15 channel words).
- **Independent assembly comparison.** `make lm-llge-differential`: 512 states for each of the 258 routines (132,096 cases, with the flight edge values of `tools/edge_cases.py` in a quarter; WCHPHASE and WCHPHOLD hold a phase, -1 to 2, and X1 is -TARGTDEX as INTPRETX sets it) run the unmodified Luminary099 rope in yaAGC (with the hardware divide) to the same stop. All 118,017 compared cases equal it in Z, all 2,048 erasable words and the interrupt-enable state. The 14,079 cases that reach a channel instruction are listed in `lm-llge-proof.json` as `waiting_for_io_channels` and are not compared.
- **Host and sanitizer results.** `make test-lm-llge sanitize-lm-llge` run the 3,690 frozen cases (every 32nd).
- **C64 execution results.** `make vice-lm-llge` runs 36 diagnostics (routine groups that fit below $c000) with 313 cases chosen by `tools/c64_row_cover.py` over every 8th host case (`cover_stride`). They take 2,178 of the 2,291 branch arcs (gcov, every linked source) the traced host cases take (`lm-llge-c64-cover.json`). The rest belong to guidance passes whose whole runs reach more code than one diagnostic holds (`c64_cover_partial`); the proof lists them (`c64_missed_arcs`).
