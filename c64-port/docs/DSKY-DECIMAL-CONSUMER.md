# Continuous original decimal display consumer

`dsky_decimal_consumer` composes genuine DECDSP41,2523 through descending canonical noun reads, DSPDCPUT table selection, supported scalar/DP scale bodies, actual DSPDCEND BANKCALL, raw-sign decimal formatter and SWRETURN row continuation. All state is committed in the sole physical image at each explicit compiled stage. Source rows repeat until actual ENTRET0136, before execution of its saved instruction, or stop before genuine CCSHOLE after clean relay selection. No native instruction decoder or new Executive poll is introduced.

Supported scale routines are bypass1, DEG2, arithmetic3, DP1/2/3 codes4/5/7/10, mission angle6 (LM landing position/CM optical angle), arithmetic14 code11 and LM360-CDUO/CM fraction13. Source selection preserves other scale entries as external continuations. HMS8, minutes/seconds9, two-integer12 and alarm0 are not executed by these stages. Input domains remain those of the immutable component kernels: ordinary stable RAM, normal/mixed noun fields, source component0..2, fresh erasable pairs where required, coherent source bank/anyEB, selecting SUPER100/120/140/160 and legal IRQ. Channel33 is an explicit stable read-only input. Caller excludes producers across all basic stage returns and supplies distinct route storage.

DP scale arithmetic reuses the released native kernel through SUPER100 metadata while retaining actual SUPER. The continuous complete-image source proof independently qualifies all four selecting forms, actual fresh reads and updated EB/BB. Raw-sign formatting preserves mixed-sign results rather than adding a source-absent normalization. Other frozen modules remain unchanged.

All4,096 uninterrupted original LM/CM inputs produce43,932 complete2052-field checkpoints identical to strict native and full ASAN/UBSAN, SHA256 `5aad80120d2b942b726a080b7d95ea004e4836a49772fc485ef0ca8a0ed4a474`. Includes every supported scale, all rows, normal/mixed nouns, factor0..19 common range, all EBs/selecting SUPER/IRQ, raw incoming A/L, signed-zero/limit operands, fresh mixed-sign pairs and selected clean-relay recovery. Original source runs continuously across all stages; no factory substitutes intermediate state.

Frozen224 original intermediate states plus11 unchanged invalid guards pass. Seven C64 stage-only builds each compare32 complete original states, all PAL VICE mailboxes `a5000020SS` for SS00..06. PRGs range5,072..16,737 bytes; maximum hardware stack29 including14 ROM bytes, software168, no additional zero page, all allocated extents belowC000. These are independent stage proofs, not an uninterrupted resident disk application. `DSKY_DECIMAL_CONSUMER_ONLY_STAGE` removes unused cases at build time; it does not change the selected algorithm.

`tools/dsky_decimal_consumer.mk` provides all/snapshot, frozen tests, full-stream sanitizer and target builds.
