# S34/35.3 and GOINT/INTINT: the TPI-to-TPF integration setup

Lane E. Milestone `lm-s3435b`.

## Scope

From `Luminary099/P34-35_P74-75.agc`, bank 35 `03377`-`03423` and
`03462`-`03521`: 53 words on 53 source lines. Seven interpretive routines of
the control-transfer ABI (`include/agc_transfer.h`,
`docs/NATIVE_TRANSFER_ABI.md`) are keyed by LOC under BANKSET at NEWOPS:

- **S34/35.3 (`35,3377`):** STQ NORMEX, then CALL LOMAT (lm-s3435).
- **S34/35.3's LOMAT return (`35,3402`):** rotates DELVLVC through the
  local-vertical matrix at 0D (VXM) into DELVEET3 (VSL1). It then pushes
  VACT3, RACT3, TIG, TPASS4 and DPPOSMAX and calls INTINT.
- **S34/35.3's INTINT return (`35,3421`):** VLOAD RATT, STORE RTARG, and on
  into NOVRWRT (lm-s3435).
- **GOINT (`35,3462`):** pushes ZEROVECS and NOMTPI, PUSH PUSH, and on into
  INTINT.
- **INTINT (`35,3466`):** STQ RTRN, then CALL INTSTALL.
- **INTINT's INTSTALL return (`35,3471`):** sets INTYPFLG from the pushed
  time (BZE), stores TDEC1, picks MOONFLAG from the pushed flag word (LXA,2
  RTX2, BON CMOONFLG), stores TET, RCV and VCV (VSR* 0,2 by RTX2), and ends
  with STCALL VCV to INTEGRVS.
- **INTINT's INTEGRVS return (`35,3517`):** VLOAD RATT, then GOTO the CADR in
  RTRN.

Each run ends at the first NEWOPS outside the routines and lm-s3435's LOMAT
and NOVRWRT: INTSTALL, INTEGRVS, or a caller's return (the CADR in QPRET,
NORMEX or RTRN).

Every interpretive pair is compiled with the shared bodies
(`src/lm_interp_steps.c`, `src/lm_interp_orders.c`). VXM runs the compiled
matrix phases (`src/matrix_native.c`, column 1) on the work-area matrix,
with the ADDRWD bias that lm-midgim's GET.LVC uses. DPPOSMAX and ZEROVECS are
read from the certified rope at the address the formation leaves.

Routines admit a canonical NEWOPS image at their LOC in FB 35 meeting all of
these conditions, and otherwise return `EXEC_OUT_OF_SCOPE` with the image
unchanged:

- EB and BB coherent, with BANKSET = BB;
- INTBIT15 set;
- EDOP, ZERO and NEWJOB zero;
- MODE `+0`, `+1` or vector;
- the VAC one of the five, with PUSHLOC no further than 40D into it (the
  integration arguments sit above the work the callers pushed);
- IRQ 0 or 1, and an allowed SUPERBNK;
- every word 15 bits.

## Evidence

Hashes are in `evidence/lm-s3435b/SHA256.json`. Bulk files are assets of the
`evidence-lm-s3435b` release (`python3 tools/evidence.py fetch lm-s3435b`).

- **Source-to-native map and independent assembly comparison.**
  `python3 tools/lm_s3435b_source.py` reassembles the unchanged file with the
  pinned yaYUL. The rope equals the certified fixed-data rope.
- **Oracle.** `tools/lm_s3435b_reference.c` (GPL, host only) runs the
  unchanged Luminary099 in the pinned yaAGC hardware-DV variant from 14336
  entries, 2048 per routine. It stops at the first NEWOPS outside the
  routines, or at POODOO1.
  - The entries sit over poisoned debris with any vectors, matrix and flags.
    One INTSTALL return in four has the pushed time zero, so BZE takes its
    branch.
  - They cover every VAC, MODE, IRQ and allowed SUPERBNK setting, and
    PUSHLOC as far as each routine's pushes leave room.
  - QPRET, NORMEX and RTRN are each one of the real callers' returns
    (`35,3572` for S34/35.3 and NORMEX; `35,3246`, `3255` for GOINT;
    `35,3246`, `3255`, `3327`, `3421` for RTRN), or a CADR in banks 2-27.

  `tools/lm_s3435b_differential.py` requires every native trampoline run to
  produce the same 2048 erasable words, interrupt state and SUPERBNK. It pins
  the stream identity (`lm-s3435b-source-stream.json`, SHA256
  `8df65fbc...5a58fe`) and archives the
  stream (`lm-s3435b-reference.snapshots.bin.xz`). `lm-s3435b-proof.json`
  lists the stops per routine. No sampled entry reaches UNIT's alarm.
- **Host and sanitizer results.** Run `make test-lm-s3435b sanitize-lm-s3435b`.
  The strict build and the ASAN/UBSAN build each pass 14436 checks:
  - all 14336 frozen digests;
  - every run ending at a NEWOPS outside the routines;
  - 91 admission guards (EB, BB, ZERO, 16-bit words, SUPERBNK, IRQ, VAC,
    MODE, INTBIT15, EDOP, NEWJOB, BANKSET and PUSHLOC for each routine).

  See `lm-s3435b-checks.log`.
- **C64 execution results.** Run `make vice-lm-s3435b`. Three PRGs each
  register only the routines their cases reach:
  - group 1: S34/35.3's LOMAT return and INTINT (256 cases);
  - group 2: GOINT, INTINT and INTINT's INTSTALL return (384 cases);
  - group 3: INTINT's INTEGRVS return and S34/35.3's INTINT return, with
    lm-s3435's NOVRWRT (160 cases).

  Each keeps the image in the RAM under KERNAL ROM (`$01=$35`). The case
  generator is integer-only, so the C64 builds the same entry images as the
  host. In VICE (PAL, stock ROMs) the three PRGs pass 256, 384 and 160
  checks with no failures (`lm-s3435b-results.json`).

## Limits

- S34/35.3's own entry (`35,3377`) is host-only. Its run goes through
  lm-s3435's LOMAT, the LOMAT return's VXM and INTINT, and those together
  outgrow C64 RAM. Each of those routines runs on the C64 in another group or
  in lm-s3435.
- S34/35.2's integration head and S34/35.5 are lm-s3435c
  (`docs/LM-S3435C.md`). S34/35.2's ACOS and Lambert setup, ELCALC and
  P34/P35 themselves are not covered. The file stays `partial`.
- Numerical validity is the original's. No wider claim is made.
