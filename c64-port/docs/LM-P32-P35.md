# Translate Luminary099 P32-P35_P72-P75

Lane E (targeting). Milestone `lm-p32-p35`. How the routines are made and checked: `docs/INTERP-COMPILE.md`.

`Luminary099/P32-P35_P72-P75.agc` (`src/lm_p32_p35.c`) is native C in full. All 923 words, in banks 34 and 35, are compiled by `tools/interp_compile.py` into 135 routines of the control-transfer ABI. The spec is `lm-p32-p35` in `tools/interp_specs.py`, Luminary's counterpart of `cm-p32-p33` (Luminary's file also holds the flag subroutines and COMPTGO, which Comanche keeps in P30-P37).

The file holds P32/P72 (CSI) and P33/P73 (CDH) with their displays, ALMXIT and ALMXITA, AVFLAGA, AVFLAGP, P20FLGON, DISDVLVC, the CSI search (CSI/A through SCNDSOL, ADVANCE), S32/33.1, S32/33.X, CDHMVR, ROTATE, INTINT2C, INTINT3P and COMPTGO. It replaces the file's earlier hand-written pieces, which stay in the tree and in the coverage record.

## Spec

- EB 7, since SUBEXIT and CSIALRM (TITER) are E7 words. CSIALRM is an alarm number 1-7 (ALMXIT's `ALARM/TB` index), and RTX1 and RTX2 are the earth or moon pair (PMINE -2,1).
- PUSHLOC is pinned low where ROTATE and ADVANCE's returns push vectors, and `self_loops` keeps P32/P72F's 60MIN loop inside its routine, as in `cm-p32-p33`.

## Evidence

Hashes: `evidence/lm-p32-p35/SHA256.json`. Bulk files are assets of the `evidence-lm-p32-p35` release.

- **Source map.** `lm-p32-p35-source-map.json` lists every word with the routine that compiles it.
- **Independent assembly comparison.** `make lm-p32-p35-differential` runs 512 states per routine (69,120 cases). All equal yaAGC in Z, all 2,048 erasable words and the interrupt-enable state. Every 256th case is frozen in `tests/lm_p32_p35_vectors.h`.
- **Host and sanitizer results.** `make test-lm-p32-p35 sanitize-lm-p32-p35` runs the frozen cases (`lm-p32-p35-host.log`).
- **C64 execution results.** `make vice-lm-p32-p35` runs 17 diagnostics with 242 cases (`lm-p32-p35-vice.log`). Fourteen routines of the CSI search run too much code for one C64 program and are compared on the host only (`c64_host_only` in the proof).
