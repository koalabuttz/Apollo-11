# Comanche restart-selected native execution

`cm_restart_native` stages positive Type C JOB requests in descending source phase-group order, then starts the existing seven-core CM trampoline. Selected native callbacks actually execute and return before job exchange. Resident mapping tables carry real source continuation tuples; unrecognized tuples, unsupported phases and reentrant staging fail before cleanup. Valid source resource-alarm mutations remain visible. Both normal STARTSB2 and counter-initializing STARTSUB staging are available.

The wrapper handles actual NUDIRECT/NUCHANG2 WOR DSALMOUT readback: channel11 becomes old-channel11 OR 2, and a slot-zero start leaves that readback in LOC. The primitive dispatcher was qualified with channel11=0; the wrapper preserves arbitrary CM channel11 without changing that primitive's established scope. Channels remain explicit external metadata.

All 64 subsets of six protected restart groups produce 320 exact checkpoints, comparing all 429 foundation words, result, actual continuation tuple, callback count and guard marker: 434 values per checkpoint. The independent host-only GPL oracle executes original STARTSB2, GOPROG3 phase verification, RESTARTS JOB admission and Executive start/ENDJOB. Callback bodies are explicitly documented two-instruction erasable test callers, INCR MPAC+2 and TC ENDJOB, whose native counterparts increment that same source word and finish. Sixteen unrelated guards remain intact. Original rope is loaded unchanged; the two-instruction fixtures are written to otherwise unused erasable caller words. These fixtures verify selected continuation execution and lifecycle composition; they do not represent translated mission flight programs or prove arbitrary flight behavior.

The snapshot SHA256 is `0fc55bb17cc785f54a944917685917feff3dee8e3b4af53db10be1b924707de8`. Native callbacks run 192 times across the 64 sequences. Tests check live 32-bit C locals, callback depth, returned frames, unknown mappings, negative-zero phase rejection and staging reentry. Host and ASan/UBSan pass. Stock PAL C64 compares all 320 frozen source fingerprints and eight full 434-word samples while executing the 192 actual C callbacks: mailbox `a500004001`; PRG 37673 bytes, text 29294, rodata 8365, BSS 886, final noinit end `$9e9f`. Stack sentinel extents are 29 hardware and 87 software bytes; no extra zero-page sections. Measurements cover this bounded diagnostic, not full-application fit.

This adapter composes the verified source operation boundaries. It does not translate MMDSPLAY, STOPRATE, the entire GOPROG3 control path, Type A/B/task/long-call restart selection, DOFSTART, arbitrary flight bodies or alarm recovery. Its source fixture and normalization provenance are described in COMANCHE_RESTART.md; all historical sources remain unchanged, and native code contains no AGC decoder or rope.

Reproduce with `make cm-restart-native-differential`, `python3 tools/cm_freeze_restart_native.py`, `make test-cm-restart-native sanitize-cm-restart-native c64-cm-restart-native` and `python3 tools/cm_restart_native_vice_test.py --vice /path/to/x64sc --rom-dir /path/to/C64 --data-dir /path/to/vice`. Before integration, add `-f Makefile -f tools/cm_restart_native.mk`. Evidence/hashes are `evidence/cm-restart-native-*`.
