# Translate Comanche055 P37_P70

Lane E (targeting). Milestone `cm-p37-p70`. How the routines are made and checked: `docs/INTERP-COMPILE.md`.

`Comanche055/P37_P70.agc` (`src/cm_p37_p70.c`) is native C in full. All 1,368 words, across 5 banks, are compiled by `tools/interp_compile.py` into 595 routines of the control-transfer ABI. The spec is `cm-p37-p70` in `tools/interp_specs.py`.

The file holds P37/P70 (return to earth): the program and its displays (P37 through P37W, P37GFRB1, P370GOFR, P370GOF, P37PROC, P370ALRM), and the RTE subroutines TMRAD100, RTEDISP, INVC100, PREC100, RTENCK1-3, V2T100, GAMDV10, DVCALC and XT1LIM.

## Compiler and spec additions

- **RTB TPMODE.** `src/rtb_modes.c` gives TPMODE a native body, `rtb_tpmode`, beside DPMODE.
- **`index_returns`.** P37PROC's `INDEX SPRTEX; TCF 0 +1` and P370GOFR's `INDEX RTENCKEX; TCF 0 +3` and `+4` return past a saved Q. The routine computes the TCF's address and the run loop goes on from there. The oracle (`tools/interp_routine_reference.c`) also stops up to four words past the case's return, and the differential keeps those words outside the file and in the bank.
- **`max_steps`.** GAMDV's iteration (GAMDV25 through GAMDV65, calling DVCALC) runs up to 144 passes of about eight routines each, and V2T100 calls it on each of its own passes. The spec raises the run loop's limit to 40,000 routines (`IRC_MAX_STEPS` for the host runner). The oracle's limit is now 4,000,000 cycles.
- **Operand seeding.** A direct operand at the top of erasable (E7,1774) no longer runs on into A and L.
- **States.**
  - EB 7, since the RTE temporaries are E7 words.
  - NN2 (GAMDV's pass count) and GAMDV30's MPAC are small negatives, so a case runs a few passes.
  - QPRET, and SPRTEX where P370ALRM's GOTO reads it, hold a CADR outside the file.
  - PUSHLOC is pinned low so pushes stay below 20D and 31D-33D (the saved returns of XT1LIM, GAMDV10, DVCALC and V2T100). The call to XT1LIM in V2T pushes four scalars, so MODE is DP or TP there.

## Evidence

Hashes: `evidence/cm-p37-p70/SHA256.json`. Bulk files are assets of the `evidence-cm-p37-p70` release.

- **Source map.** `cm-p37-p70-source-map.json` lists every word with the routine that compiles it.
- **Independent assembly comparison.** `make cm-p37-p70-differential` runs 512 states per routine (304,640 cases). All equal yaAGC in Z, all 2,048 erasable words and the interrupt-enable state. Every 256th case is frozen in `tests/cm_p37_p70_vectors.h`.
- **Host and sanitizer results.** `make test-cm-p37-p70 sanitize-cm-p37-p70` runs the frozen cases (`cm-p37-p70-host.log`).
- **C64 execution results.** `make vice-cm-p37-p70` runs 56 diagnostics with 700 cases (`cm-p37-p70-vice.log`). Every routine, including the V2T, GAMDV and DVCALC iteration, runs on the C64; no routine is host only.
