# Second review: R30 entry states in flight (#604)

Second certificate reviewer, 2026-10-18. Lane E's #604 (head bc29c5a5) refreezes `r30` with the entry states R30 meets in flight. The same PR adds the lm-tff-abi table and the LM DOI flight scenario. **Verdict: accepted, and the LM and CM R30 certificates are re-cited to this record.** The previous record is [rev2-recite-e532.md](rev2-recite-e532.md).

## Code

- **`novac`: V82CALL, V82CALL +1, V82GOFF.** V82 starts in a NOVAC job, so these three run with FIXLOC 0110 until V82GOFLP's FINDVAC. `sane()` accepts vac 0110, and the differential draws it at those points in a quarter of their cases.
- **`any_fixloc` and `any_newjob`.** Basic routines that never name FIXLOC or NEWJOB move to `at_basic_nv` and `sane_nv`, which take any FIXLOC and NEWJOB +0, positive or -0. An example is TICKTEST, a WAITLIST task that sees NEWJOB -0 while DUMMYJOB idles. The differential draws any FIXLOC in half the cases at those routines and NEWJOB -0 in a quarter.
- **A new compiler rule.** Under `any_newjob`, a routine is left out if its own `CCS NEWJOB` refuses -0, because its fourth skip is data. R30's return from FINDVAC is the one affected, and it is run only by a job.
- **Domain.** Both certificates' `supported_domain` now name the NOVAC FIXLOC at the three points and the any-FIXLOC and NEWJOB -0 rule at basic routines that don't name them.

## Notes (non-blocking)

1. **0110 is accepted beyond its three points.** The generated `sane()` accepts vac 0110 at every interpretive routine, while cases draw it only at the three novac points. This is the existing STATEINT pattern, and flight reaches 0110 only in V82's NOVAC job. A per-point gate at a later generator change would make the code match the domain wording.
2. **The NEWJOB regex misses one spelling.** The new rule is needed because `\b067u?\b` does not match the `00067u` spelling. Other NEWJOB orders in that spelling also escape the `any_newjob` exclusion. That is safe today because the differential draws -0 at every `_nv` routine. Lane E has been told.
