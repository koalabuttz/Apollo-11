## Notes (not blocking)

- **Shared-source drift.** `lm_interp_orders.c` and `tests/interp_case.c` changed after the freeze. `make findcduw-differential` now regroups the C64 rows (group 13 31→30, group 14 33→34) and fails its final `git diff` (tools/mk/findcduw.mk:27). The committed rows still cover every host arc and pass on VICE. Re-freeze at the next touch.
- **Untested arms in unentered return-point routines.** Some per-return-point routines are never entered by flight callers, because real calls run inline. Some of their arms go untaken, for example `lm_findcduw.c:1261` and the CCS TEM2 '-' arm at `:4579`. The same AGC paths are compared in the routines flight uses.
- **INDEX end-around carry (cross-lane).**
  - `index_carry16` (tools/interp_compile.py:1593-1599) matches yaAGC's AddSP16.
  - It applies only to this spec. Certified specs compiled without it take 0 carries in their frozen rows, except rtb-op-codes.
  - In rtb-op-codes, 18 C64 rows run `INDEX A / CAF LIMITS` with A = -1 (Luminary099/RTB_OP_CODES.agc:116-117, 142-143; Comanche055/RT8_OP_CODES.agc:141, 186). Those rows read DPOSMAX instead of POSMAX on the 6502. Both hold 37777, so the results agree only by coincidence.
  - Reported to the steward. The fix is to make the carry the compiler default.
