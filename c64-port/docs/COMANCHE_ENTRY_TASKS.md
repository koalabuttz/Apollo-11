It stores -TIME1 into physical E6 TUSED `03312`, sets JETAG `03311` to one, applies original PHASCHNG word1 to clear group1 protection, and enables the external IRQ latch through original RELINT. Physical bank15/E6 is a caller obligation. `cm_setjtag_callback` binds the actual source 2CADR to the native WAITLIST trampoline, returns before TASKOVER, and retains no suspended C frame.

The independent oracle proves the whole original task body, including all erasable words plus SUPERBNK/IRQ/status. Host and target diagnostics additionally invoke 1024 actual sequential native WAITLIST callbacks with stack guards and reentry refusal. That callback harness uses a transient queue fixture; its queue admission state is separately covered by existing CM WAITLIST proofs, and is not described as a whole-image source scheduler/application integration proof.
