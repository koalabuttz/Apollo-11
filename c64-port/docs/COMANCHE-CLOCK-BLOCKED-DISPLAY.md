It records the actual source-selected transfer. The unchanged original external-monitor flag and suspended interpreter cores survive; no normal-display defaults or factory replacement are inserted. Each helper returns normally before any overlay replacement, with no extra scheduler/IRQ poll.

This completes the seven genuine blocked mission contexts1,4,5,8,9,12,13 that were deliberately outside the earlier normal N40 consumer.
