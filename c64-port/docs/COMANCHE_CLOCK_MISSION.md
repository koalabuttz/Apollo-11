# Comanche continuous CLOCKJOB mission composition

This stage adds actual CLOCKJOB and display control continuations to the CM resident service resolver. One canonical 2048-word erasable image remains authoritative. Each compiled callback returns before a disk overlay replaces the previous module; native metadata stores only control pointers, the original source-selected tuple, and interrupt continuation flags.

The independent original Comanche source corpus contains 448 continuous sequences and 3392 complete checkpoints. Cases 0–383 begin at DANZIG with a real pending T3 interrupt and execute the original task ISR, selected task, WAITLIST/admission/delay services, TASKOVER, hardware RESUME and Executive selection. Cases 128–191 set NVWORD1 to actual V06N40 before the interrupt: CLOKTASK admits CLOCKJOB through NOVAC, and DANZIG selects its actual 03332/050066 tuple. The compiled body executes CLOCKJOB → BANKCALL → QUICTRIG → SWRETURN → CKNVWRD1 → REGODSP → SAVELOCS, stopping at actual MAKEPLAY 02770. That consumer continuation is retained for the next module.

Cases 384–447 independently enter actual CLOCKJOB 03332/050066 with NVWORD1=+0 and a valid suspended interpreted job in another core. CLOCKJOB executes its real trigonometric and return groups, CKNVWRD1 selects ENDJOB 05217, and the canonical CM finish bridge releases the active core and resumes the suspended interpreter at original NEWOPS 06037. These are separate source entry cases; they do not claim that a zero-NV CLOKTASK admitted a job. Earlier zero-NV CLOKTASK cases only reschedule the task and update TBASE6, as documented by the prior mission scope correction. Other ISR cohorts retain actual interpreted NEWOPS or the selected NBDONLY tuple; this stage does not execute the NBDONLY body.

The resident extension identifies exact compiled source entries for CLOCKJOB, QUICTRIG, its source return, CKNVWRD1, and REGODSP/CLOCPLAY/GOFLASH. General CM body modules retain ownership of numerical/display behavior; the extension composes them without changing their source-qualified code. END and idle dispatch retain the seven-core CM semantics. An unknown selected continuation returns unmapped and remains visible in the canonical image.

The fixture combines byte-identical original EXECUTIVE, WAITLIST, INTERRUPT_LEAD_INS, INTERPRETER, P40-P47, CM_ENTRY_DIGITAL_AUTOPILOT, POWERED_FLIGHT_SUBROUTINES, SINGLE_PRECISION_SUBROUTINES and INTER-BANK_COMMUNICATION from this repository. Previously audited indentation-only repairs apply where necessary; historical originals are unchanged. Supporting Virtual AGC is pinned to 1b5d6474841a7ab53237ead070f76f35f162f68d. The assembled rope equals the corrected baseline SHA256 2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79. Counter drivers are zero and the reference scaler is held fixed. The retained complete source/native text stream SHA256 is e188e160109500ca7907c129d62d79f23b8ecca485d87de260b4d37daf1dd4f5; A/L/Q retain all 16 register bits. Each checkpoint compares all 2048 physical words, SUPERBNK, interrupt enable, ISR/substitution flags, and the actual typed Executive continuation.

Strict host and full ASAN/UBSAN validation pass all 448 sequences. The real production C64 disk fixture loads six native control/body modules and two proof modules into the single $8000–$bfff slot. The seven representative source cases 0,64,128,192,256,320,384 run under both incoming C64 IRQ states: 14 continuous sequences and 106 complete source checkpoint fingerprints, plus a complete physical sample and final whole-image comparison. The unchanged five prior body payload sizes are 3015,7768,5353,4215,9671 bytes; the CLOCKJOB/trigonometric/display module is 5129 bytes. External latches occupy $c400; transient runtime and call metadata have explicit size bounds at $c430 and $c460. The software stack remains confined to $c800–$cfff. The C64 loader restores incoming I/D/$01 and holds producer exclusion across each source callback and slot load.
