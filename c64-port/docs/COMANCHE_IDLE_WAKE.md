The final job body remains a separate compiled consumer; this module invents no flight payload or end-of-job completion.

The qualified composition starts at the actual bank00 SERVICE_ROUTINES `TC JOBSLEEP` caller, Q03761/EB6/SUPER060, with one active NOVAC core0 and six unused -0 cores. Source wake FCADR051332 identifies CLOCKJOB's genuine bank24/3332 address. The image contains a pending source WAITLIST WAKER task and its real DELAYLOC slot; prior DELAYJOB/WAITLIST insertion is not executed or credited by this cohort. All eight delay slots, raw L corners and both initial interrupt-enable states are exercised. The factory builds typed source inputs only; it does not replace any image between source groups. Source selection, task completion, external interrupt metadata and the final bank transfer are retained exactly.

All 512 uninterrupted original source executions, 4,608 complete checkpoints, match strict native C and the full ASAN/UBSAN stream. SHA256: `50c6a671cd1bb667735d9b30c9890c43b3cb4cecbec48709af7af39d9134c1bf`. Every checkpoint includes all 2,048 canonical words, all 13 external latches and both interrupt metadata fields. Eight complete unchanged source paths execute on stock PAL C64, 72 checkpoints in total, covering all eight delay slots. Each compiled phase returns before the next disk overlay loads. The resident holds producer exclusion across the nine-group sequence and restores both incoming hardware I states and ROM mapping afterward. The checker compares source fingerprints for every field, two full 2,063-field samples and the externally captured final canonical image. Metadata is resident diagnostic scratch only; native Executive views are transient and the canonical image remains authoritative. Source-algorithm bodies are unchanged previously verified modules. The new helper intentionally represents this bounded sequence. A false result can follow a genuine source service outcome outside the sequence and does not promise transaction rollback. Other schedulable jobs, concurrent producers, prior task insertion and execution of CLOCKJOB/display are separate qualification work.
