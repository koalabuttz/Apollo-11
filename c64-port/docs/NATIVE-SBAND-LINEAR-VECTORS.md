# Canonical native vector multiply, add and subtract

`sband_vector_linear(image, mission, operation, fixed_operand)` implements original VXSC, VAD and VSU. LM entries are 07401, 06751 and 06747; CM entries are 07350, 06720 and 06716. VXSC admits DP scalar MODE +0 or vector MODE -1; VAD/VSU require vector MODE -1. All end before the actual mission DANZIG, leaving source pending caller LOC/EDOP, PUSH/VAC and external IRQ/SUPER intact except genuine operand aliases. No instruction decoder, interpreter scheduling or external callee executes.

Ordinary 15-bit canonical words/Q, raw 16-bit A/L, ZERO +0 and coherent EB/FB/BB are required. A null operand pointer reads live source erasable words through ADDRWD and current EB: logical 030..1772, mapped physical at least 030, contiguous source operand within a bank. A supplied fixed object has six ordinary words, belongs to the caller, stays immutable/non-aliasing throughout the call, and corresponds to the actual source fixed descriptor: 2000..3772 or 4000..7772. Vector-times-scalar uses only the first two words, while scalar-times-vector/add/subtract use all six. The caller retains ownership and excludes scratch/operand producers throughout the native continuation. Unsupported contexts preserve the entire image.

The native source explicitly implements source operand order and exchanges. DMPSUB reads the major operand after its minor partial-product writes, so scratch aliases remain live. Scalar-times-vector advances ADDRWD by four and sets vector MODE. Vector-times-scalar retains ADDRWD. VAD/VSU retain their original ADDRWD +030000/+040000 markers and load Y, Z, then X in source order; the native function does not decode these marker words. Raw overflow corrections retain original BUF/L/OVFIND and select Q 3 only when an overflow helper genuinely returned.

Fresh input-only GPL original-engine oracles, native strict and full ASAN/UBSAN agree on all 131,072 complete 2048-word states plus SUPER/IRQ/status. Sixteen groups cover both missions, scalar/vector multiply, add/subtract, live erasable scratch aliases and supplied fixed data. Sampled tuples include signed-zero and overflow corners; no exhaustive Cartesian or instruction-edge claim is made. Fixed-data oracle groups inject six independently constructed input words at the original passive HIUNITX table region, leaving all original instruction and scalar-constant words untouched. The source-map records the unchanged baseline rope identities and this input injection separately.

The stock-ROM PAL C64 diagnostic compares 512 frozen complete states word by word. Target PRG/map and mailbox identities are retained in the proof. Diagnostic fixtures and two images are not full-application memory. Unique retained-source integration targets are `test-sband-linear` and `sanitize-sband-linear`.

This reusable arithmetic dependency supports antenna and ephemerides composition. Both containing antenna and INTERPRETER files remain partial.
