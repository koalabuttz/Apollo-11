# Compile Comanche alarm call-site operands into native constants

Lane A. Milestone `cm-alarm-sites`. Interface: `docs/NATIVE_TRANSFER_ABI.md`.

The alarm code after every genuine Comanche055 `TC ALARM`, `TC ALARM2`, `TC BAILOUT` and `TC POODOO` (62 sites) is now a compiled constant generated from the original source listing, so the native ALARM_AND_ABORT entries no longer read a copy of the rope at runtime. All 11,904 site/context cases match the existing native entries fed the original rope words (859,919 strict and sanitizer checks), and 372 sampled cases match the host digests in VICE.

## Scope

Comanche055 ALARM_AND_ABORT.agc entries that take their alarm code from the word after the caller's `TC` (ALARM, ALARM2, BAILOUT, POODOO). Auditor finding 1 (2026-10-11): `cm_alarm_fixed_address`, `cm_alarm2_fixed_address` and `cm_abort_word_fixed_address` resolved that word by reading the rope at runtime. They are gone from `src/`; the legacy differential harnesses keep them as test-only probes in `tests/cm_alarm_rope_probe.h`.

A fixed Q that is not a genuine call site is `EXEC_OUT_OF_SCOPE`: no original producer supplies it. Erasable inline words are still read from the image after the original store.

## Source map

| AGC | Native |

| ALARM entry | `cm_alarm_site_call` (wraps `cm_alarm_complete`) |

| BAILOUT/POODOO post-VAC word (ALMCADR 01363) | `cm_abort_site_call` (wraps `cm_abort_word`) |
| operand lookup | `agc_transfer_operand`, `agc_site_lookup` (`src/agc_transfer.c`) |
