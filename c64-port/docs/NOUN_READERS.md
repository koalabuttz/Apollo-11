The original Luminary099 and Comanche055 PINBALL_NOUN_TABLES files are translated as three native C routines plus all six immutable noun/scale tables. This completes those two files within their documented caller domain; it does not complete Pinball, its numerical scale routines, or either full application.

The API in include/noun_reader.h reads and writes the sole authoritative 2,048-word image. LODNNTAB loads NNADTEM, NNTYPTEM and MIXBR, and the mixed-noun component/routine scratch words when applicable. GTSFOUT and GTSFIN load their two-word factors. The implementation also preserves the original A/L/Q side effects and DXCH-Z bank return: a normal noun leaves Q pointing after the original TC, while a mixed noun leaves its IDAD table offset. All ten physical scratch aliases are independently assembled from both originals and compile-time checked for equality. No mutable noun table, source instruction decoder, or AGC execution engine is present in the native module.

Supported inputs are nouns 0 through 99, either sign of zero, and all original even scale-pair indices: 0 through 56 for LM and 0 through 38 for CM, also either zero. Callers provide an original entry PC, FB=064000, SUPER100/120/140/160, consistent retained EB/BB, ZERO=0, and an logical return PC0000..07777 (including register/erasable returns) in A with its bank pair in L. The original first exchange corrects A/L overflow. Ordinary RAM values are caller-owned 15-bit words; A/L/Q retain their full register representation. Producers must be excluded during a call. Invalid context or index returns false without changing any image or I/O word. Reading adjacent instruction words through an illegal table index is outside the source's documented reader domain and is rejected explicitly.

tools/noun_reader_audit.py maps every noncomment original line: 41 assembled algorithm words per file, all 556 LM and 520 CM table words, MIXCON and placement/count directives. The full table proof remains in docs/FIXED_DATA.md. Both noun source files enter the independent assembled fixtures byte-for-byte with no indentation repairs. The independent host oracle links only input constructors and the GPL Virtual AGC engine, executes the actual original assembled readers, and stops after their real caller bank/PC return. The native target links none of that GPL engine. A full-state comparison checks 58,368 cases: every noun and scale pair, both signs of zero, eight retained EBANKs, six caller contexts including both overflow-sign corrections and all four SUPER latch forms, both initial interrupt states, and patterned values across all physical words. Strict host tests additionally check 100 invalid contexts for complete image/I/O preservation. ASAN and UBSAN check both supported/rejected calls and all source-matching output states. Leak detection is disabled because the managed executor's ptrace environment does not support it; this implementation allocates no heap storage.

The C64 diagnostic executes 1,216 cases covering every noun and scale pair in both missions under every SUPER latch form. Sixteen potentially modified words come from independently frozen original outputs. The other 2,032 words are compared individually with the constructor's original image; freezing verifies that the source leaves those words unchanged. SUPER and interrupt state are also checked. Thus no checksum substitutes for state comparison. The stock-ROM PAL VICE result is mailbox a5c004, with a 19,787-byte native PRG loaded through $5549 and diagnostic BSS ending at $754a. The diagnostic's two transient images and expected fixtures are test storage; it does not claim the application resident scheduler or disk-overlay placement. The reusable module accepts the application's canonical image through its ABI.
