# Completed-pair DANZIG source exchange

`lm_danzig_change` implements original Luminary `DANZIG` at 06061 or `NOIBNKSW` at 06063 with EDOP positive zero and a positive NEWJOB core offset. DANZIG restores BANKSET before the source NEWJOB check; NOIBNKSW retains the incoming banks. The compiled check performs the source CCS debris and enters the previously qualified canonical CHANG2. It reaches actual selected basic DTCB or interpretive INTRSM/NEWOPS. It fetches no AGC instruction or interpretive opcode.

Caller-owned producer exclusion spans the source check and exchange. The callback must import the resulting Executive and adopt the actual selected source continuation through the existing exchange action. Repeating lifecycle, IRQ admission or another NEWJOB poll would change source behavior.

The independent unchanged-original oracle covers 16,384 complete 2,053-word states: transfer, all 2,048 erasable words, SUPERBNK and source interrupt permission. Strict and full ASAN/UBSAN streams agree exactly, including both scheduler entry paths, all selected core slots, basic/interpreter returns, both IRQ states, signed zeros and uncorrected A/L/Q encodings. Sixty-four complete frozen entry/exit pairs pass on stock-ROM C64 with actual disk fixture overlays. All 25 rejected domains and three null interfaces preserve image, I/O and transfer output.

The other EDOP/NEWJOB branches remain outside this adapter. This is source-exact scheduler glue, not a claim that the containing interpreter or Executive file is complete. Run `make -f tools/lm_danzig_change.mk test sanitize` against the retained compressed source stream. The proof manifest retains exact source dependencies, target artifacts and measured stack usage.
