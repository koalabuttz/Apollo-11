# Original LM/CM internal NVSUB continuations

`dsky_nv_continue` provides explicit native entries for the remaining internal source groups surrounding NVSUB admission and return. NVSBCOM/NVSUBCOM finish at actual NVSUB1, KILMONON returns to its fixed caller, ENTSET/ENTSET-2 and NVSUB2's noun-only return execute NVSUBEND/SUPDXCHZ through the saved caller, NVSUB2's first formatter return reaches the next UPDATNN entry, and its final formatter return/ENDNVSB1 reaches ENTPAS0. The selected formatter or ENTPAS0 body remains separate. Both missions retain their actual fixed addresses; common bank-41 addresses are source-identical.

The image is authoritative and IO explicit; callers exclude producers. Source NVSBCOM accepts A0 or1, fixed Q02000..07776, so NVSBWAIT's available path retains its source return offset. Saved caller-return pairs obey the separately verified NVSUBEND domain. Incoming banks are coherent, RAM ordinary and SUPER/IRQ legal; internal bank-41 continuations require source SUPER100 set. Unsupported contexts leave the entire image and IO unchanged. There is no decoder, heap, floating point or scheduler poll.

All18,432 complete original states across18 mission/entry combinations match strict native and full ASAN/UBSAN output, SHA256 `f06687efb69ed25382e6bf538edc6ee0898e7992437416a876c167695f1063a5`. The corpus covers both source return offsets, bank/EB/SUPER classes, raw A/L, caller returns and scratch aliases. In particular, final NVSUB2 cleanup clears source LOADSTAT01014 and retains01041; direct ENDNVSB1 preserves raw A overflow bits. Frozen states include both cases.

The frozen checker passes72 whole states and180 unchanged invalid guards. PAL C64 in VICE passes the same72 original states: mailbox `a500004800`, PRG6,299 bytes, hardware stack14 bytes including14 ROM bytes, software stack38 bytes, no added zero-page allocation. Full streams are compressed and exact source/dependency/target identities recorded in `evidence/dsky-nv-continuation-proof.json`. `tools/dsky_nv_continuation.mk` supplies full-route `all`, frozen `test`, complete-stream `sanitize` and target builds. This is bounded source-group qualification, not a whole Pinball certificate; the original GPL engine remains host-only.
