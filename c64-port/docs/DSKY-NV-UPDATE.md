# Original LM/CM verb and noun update

`dsky_nv_update` executes original bank41 UPDATVB/-1 and UPDATNN/-1 through the actual fixed caller. Noun updates call the already source-qualified immutable LODNNTAB reader, apply source CCS/SETNCADR behavior, then use the actual mission DSPDECVN and GOVNUPDT/POSTJUMP return. The image remains authoritative; all scratch, register, bank, relay and IRQ effects survive. Source noun types that request a machine/channel address retain NOUNADD/EB as required, while ordinary ECADRs update them.

The four explicit entries accept0..99 from A or the existing VERBREG/NOUNREG as appropriate, fixed caller Q02000..07777, source bank41/SUPER100, any coherent EB and ordinary RAM. The selected relay word must be nonzero. Unsupported contexts preserve the whole image and IO; producers must be excluded by the caller. Both missions' fixed tables must be available in this shared build. No generic instruction decoding, heap, floating point or extra scheduler poll is used.

All8,192 complete original-source states agree with strict native and full ASAN/UBSAN streams, SHA256 `f4885c0bf248f0d39b1b2c0a80dea97e9adc2f6104ac107f71b524c61f73eb3f`. Every verb/noun0..99 is exercised through all four entries in both missions, with all EBs/IRQ states, varied raw L/A where source permits, original third-limb formatter scratch and preserved memory. No noun40/85 substitution or manufactured formatter result is used.

The frozen checker compares128 full original states and96 unchanged invalid guards. PAL C64 in VICE passes the same128 states: mailbox `a500008000`, PRG28,505 bytes, hardware stack18 bytes plus14 ROM bytes, software stack105 bytes and no additional zero-page allocation. Target dependencies use their existing strict warning contract and omit Wconversion for frozen enum promotions; owned integer and host source checks retain it. Full streams are compressed; exact source/dependency/target identities appear in `evidence/dsky-nv-update-proof.json`. `tools/dsky_nv_update.mk` supplies full-route `all`, frozen `test`, complete-stream `sanitize` and target builds. This closes the bounded update bodies, not the selected caller or the whole Pinball file; GPL original-engine comparison is host-only.
