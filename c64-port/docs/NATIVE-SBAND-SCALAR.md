The native scalar kernels map the original LM and CM interpreter DMP1, DAD and DSU basic entries to explicit C arithmetic. They support the ordinary double-precision caller state needed by antenna and ephemerides calculations. Both containing INTERPRETER and antenna source files remain partial; this packet earns no whole-file credit.

`sband_scalar(image, mission, operation, fixed_dp)` operates on the single canonical 2,048-word erasable image. It accepts MODE+0, coherent EB/FB/BB, ZERO+0, ordinary RAM/Q and raw 16-bit A/L. The entry PCs are LM DMP07572/DAD06775/DSU07005 and CM07541/06744/06754. These entries are fixed-fixed: the current FB remains selected for their banked operands. Successful calls stop before the original mission DANZIG, LM06061 or CM06030, without executing scheduling or another interpretive pair.

ADDRWD identifies either a live ordinary erasable pair, including supported scratch aliases, or an immutable caller-supplied fixed DP object with exactly two readable ordinary words. Erasable addresses must resolve above the CPU/editing-register region; a banked EB0 descriptor that resolves into that region is rejected. Fixed descriptors must not cross their selected bank. The supplied fixed object must match the original caller data at that descriptor and must not alias the image; the numerical kernel neither owns nor fetches fixed storage. This two-word interface is separate from the six-word fixed operand interface of the vector kernels.

DMP keeps the unrounded triple product. Its minor operand is fetched first, and its major operand is fetched after the source MPTEMP/MPAC writes, preserving live aliases. DAD/DSU load the source pair before updating MPAC and follow the actual double-add and overflow carry path, preserving signed zeros, BUF, OVFIND, raw A/L and the source Q. DMP returns with Q3; addition/subtraction retain incoming Q unless the actual overflow subroutine runs, in which case Q3 remains. Pending LOC/EDOP, PUSH/VAC state, banks and external SUPER/IRQ remain as the source dictates. Invalid mission, operation, source state, descriptor or fixed word preserves the complete image.

The native arithmetic privately reuses the MIT raw-operation semantics already qualified in the frozen vector kernel. It does not link the GPL reference engine, inspect source opcodes or dispatch historical instruction words. The independent input-only oracle runs the actual original entry and complete helper bodies. LM original interpreter bytes are unchanged; CM retains the previously audited indentation-only repairs without numerical changes. Baseline original-layout rope identities remain distinct from the two passive fixed input words supplied by each test case.
