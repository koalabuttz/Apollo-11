# CM restart table and variable selection

`cm_restart_select` translates RESTARTS at `01,3520`, PHSPART2 at `01,3755` and GETPART2 at `01,3533`. Type A tables and variable Type B/C records select original NOVAC/FINDVAC/WAITLIST/LONGCALL or INITDSP service entry. The explicit exit tells the resident which original service to execute before entering the next table part. All 62 nonzero original odd table entries and 12 even table parts are exercised, including group aliases, display phase1, indirect times, source negative priorities and second table parts. The source `CA RTRNCADR` literal is `04675` (TC SWRETURN), not the symbol address. Indirect timing reads retain original BB/SUPERBNK behavior.

`cm_restart_table_data.h` contains only 249 original scalar priorities, duration words, addresses and index constants at `01,2000..2370`; no executable rope is retained. Original RESTART_TABLES SHA256 is `4ed25b96c1e8582bf1656b433e0212eb6c9f5528348b40f5c7117a1964ab9994`, with zero repairs. Original table2.3 alone uses fixed 600SECS, represented as exact source DP `(3,025140)` = 60000 centiseconds; other indirect durations come from the canonical image.

The oracle is host-only GPL Virtual AGC at `1b5d6474841a7ab53237ead070f76f35f162f68d`. The fixture overlays byte-preserved original translated sections onto pinned corrected supporting sources. The service fixture's indentation-only repairs and pinned-support domain are recorded in `COMANCHE_RESTART.md`; the assembled rope is `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`. Historical originals are untouched. This qualification does not silently adopt the separate globally-original ERASABLE_ASSIGNMENTS domain: that source has the documented stray `-16` line and different ALTVAR/R53FLBIT addresses; none of these groups uses those symbols.

Each comparison includes every 2048 physical erasable word, raw A/L, source Z/Q/banks and exit status. Autonomous drive-counter inputs are held zero, source scaler updates are frozen, and no output words are normalized. Native code is MIT, uses the sole canonical image, and contains no AGC decoder or executable rope. External SUPERBNK/IRQ latches remain separate metadata. Source-selected service calls require resident composition after the current C frame returns. The standalone diagnostic proves its documented states and resource bounds, not whole-application overlay fit or WCET.

6144 independent original-source cases and the host ASan/UBSan diagnostic pass; each state is checked against its frozen full-image fingerprint plus two complete 2049-value states. Snapshot SHA256 is `17ba77cdbbe47d6c913c9a3ee3044d0cfc9dddbad8947d10570a0bc1a7468cc1`.
