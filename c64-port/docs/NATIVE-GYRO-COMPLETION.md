# Native gyro wake and IMU completion

The new `imu_gyro_end` canonical adapter executes the actual Luminary099 and Comanche055 gyro completion paths. It starts at the `JOBWAKE` call left by `STRTGYRO`'s completed phase, follows `NORESET`, `IMUFINED`, the cage/ISS-warning checks and the IMU-device `BADEND`/`GOODEND`/`ENDMODE` sequence, and stops at the literal `TASKOVER` entry. A second entry covers the actual `IMUBAD` boundary produced by deferred gyro segmentation. The original full Executive wake search is composed using the frozen mission-specific basic-wake adapters; there is no instruction or interpreter decoder.

All 2048 canonical erasable words, raw 16-bit A/L, IRQ, SUPER and channels11/12/14 are compared with the unchanged original assembly. The four constructor contexts contain 65,536 cases each (262,144 complete states). Every strict-native and full ASAN/UBSAN result equals the source bytes. The corpus varies ordinary incoming register words, all source +/-zero/-1/positive MODECADR classes, warning/cage outcomes, both sleeping-job matches and no-match cases, legal saved basic banks, all Executive cores and preserved device words. This is the stated deterministic constructor corpus, not an exhaustive Cartesian test of all possible canonical images.

The source differs between missions: LM's `EXTEND/BZF` following `CCS MODECADR` sends negative sentinels directly to the store with A=+0. CM omits those words and performs the second wake search. Its no-match return has LOCCTR=-1, so the source indexed `ADS LOC` changes MODE at0163. The adapter preserves this literal effect. A/L exchanges, wake priority/new-job selection, channel preservation and source L normalization are retained.

The contract requires nonnull exclusively owned image/I/O objects; ordinary source bank07, coherent EB/BB/SUPER, ZERO=0; IMU device0; MODECADR positive or +0/-0/-1; a complete valid basic-wake Executive arena with current positive core0, no +0 candidate priorities and legal dormant saved banks. The gyro/device counters remain quiescent under caller producer exclusion. Rejected unsupported states are not promised transactional rollback after a composed helper has run. Successful source return is IRQ0 except direct bad sentinel paths retain the original caller IRQ.

Four actual PAL C64 PRGs validate 32 original-only frozen complete states each (128 states total), including unowned memory. Compiler zero-page allocation is disabled; the retained maps, stock VICE mailboxes and both stack guards are checked. The largest PRG is 11,308 bytes; measured maxima are 25 hardware-stack bytes and 762 software-stack bytes. The target keeps the frozen wake-helper enum signedness warning visible with `-Wno-error=sign-conversion`; strict host builds retain all warnings as errors.

The source mapping independently checks each included instruction against the byte-original mission rope, preserving the earlier IMU source audit and disclosed CM indentation-only repairs. Source/native/sanitized complete streams are retained once per context as deterministic XZ, with decoded hashes and logical roles in the proof ledger. Existing frozen lead-in, task, RTB and UNIT bytes are untouched.

This packet closes the bounded source gyro wake and IMU completion bodies. It does not execute TASKOVER/RESUME, sleeping interpreted jobs, the gyro output-counter consumer or actual physical IMU pulses. Remaining containing-file and RTB entries retain explicit frontiers; no whole IMU/RTB/application completion is claimed.
