# Comanche canonical FIXDELAY/VARDELAY

`cm_delay_image` executes original FIXDELAY/VARDELAY through actual TASKOVER entry. FIXDELAY takes a compiled source literal and queues the actual Q+1 continuation; VARDELAY takes A and queues Q. The source BBCON is the caller's physical BB plus its external SUPERBNK. The helper composes the qualified WAITLIST insertion, preserves the source scratch/register debris and returns at 05324 rather than keeping a suspended C frame. Callers must already be under WAITLIST control with interrupts inhibited, an ordinary positive bounded delay and a valid nonfull queue. The fixed caller's literal comes from a certified compiled mapping, never executable rope access.

All 1024 cases compare every 2048 physical word plus external SUPERBNK/IRQ and status against original assembly: 512 actual SVCT3 FIXDELAY calls (literal 500 at 07720, continuation 07721) and 512 VARDELAY calls, all eight erasable and 32 fixed banks, SUPERBNK settings and insertion positions. Host and ASan/UBSan pass all whole-image fingerprints and two complete 2051-value states. Snapshot SHA256 is `6a394d3bd35723ce86d9565a2a16e7c426c2996e1ed276d196293ea758768a5a`. Counter-drive inputs are zero, the scaler is frozen, and no output word is normalized. Host-only GPL oracle executes Virtual AGC `1b5d6474841a7ab53237ead070f76f35f162f68d`, with original WAITLIST's nine audited indentation-only repairs and pinned corrected supporting sources. Fixture rope SHA256 is `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`; historical originals are untouched.

PAL C64 passes 128 representative whole-image fingerprints and one complete 2051-value sample, mailbox `a500008000`. PRG 19314 bytes, text 6980, rodata 12320, BSS 4122, image end `$638b`, hardware/software stack extents 18/84 bytes, no extra zero-page sections. Native code is MIT, retains the sole canonical flight image, and contains no AGC decoder or persistent flight-state duplicate. Producer exclusion is caller-owned. This standalone diagnostic does not establish whole-application fit or WCET.
