# Comanche 055 ENEMA

The MIT `cm_enema` translates original CM LIGHTSET, STARTSB2/STARTSUB selection, RASFLAG integration-bit clearing, conditional TVCEXEC WAITLIST publication and complete phase agreement checking. It stops at the explicit MMDSPLAY, PTBAD or DOFSTART continuation boundary. It does not resume a suspended C stack or execute those later bodies.

Source differences matter. CM ENEMA normally preserves TIME3/4/5; the fresh route performs STARTSUB cleanup and counter initialization before reaching DOFSTART. LIGHTSET requires navigation MARK REJECT and either main or navigation error-light reset code. TVC scheduling occurs only for FLAGWRD6 high bits040000, with delay50 and actual TVCEXEC tuple02720/034066. Native publication retains WAIT scratch aliases, queue interval ordering, NEWPRIO/LOCCTR changes and source Q debris, including Q=3 after actual TC Q returns. RASFLAG clears the original integration bits only on the ordinary route.

All 4,096 independent inputs match original assembly on every one of 439 owned words plus status, including raw16-bit A/L, Q, physical BBANK/SUPERBNK and interrupt enable. Cases cover fresh/ordinary key combinations, all four DAP flag encodings, timer insertion corners, all six phase-fault groups, trap latches and channel cleanup. Sixteen unrelated guards remain intact. Snapshot SHA256 is `ea9d5d06fa5c2e564f9c841ac3aa5aa73ddcdefa56d7564b6b656623b8b0fad8`.

The host-only GPL oracle executes the original source overlay and links no native implementation. Shared fixture/provenance is `tools/cm_services_prepare_reference.py`: pinned Virtual AGC commit `1b5d6474841a7ab53237ead070f76f35f162f68d`, byte-identical originals, explicit indentation repairs, and whole-rope equality against independently assembled pinned corrected source. Rope SHA256 is `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`; original/normalized fresh-start hashes and exact repairs are recorded in COMANCHE_RESTART.md and `evidence/cm-services-*`. Historical originals remain untouched.

Host and ASan/UBSan pass all 4,096 complete-state fingerprints, eight full samples and unsupported-bank/register/counter no-mutation checks. Stock PAL C64 also passes all 4,096 fingerprints and eight full 440-value samples: mailbox `a500000010`; PRG38231 bytes, text14683, rodata23534, BSS879, final noinit end `$a0c6`. Measured sentinel extents are27 hardware and23 software stack bytes, with no extra zero-page sections. The original 6-billion-cycle diagnostic limit was insufficient for this corpus's repeated full-state hashing; the checked-in helper permits30 billion cycles and produced a complete PASS. This is a diagnostic budget, not flight timing or WCET evidence.
