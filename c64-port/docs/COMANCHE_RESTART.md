# Comanche 055 restart foundation

The MIT `cm_restart` translates CM STARTSB2 cleanup, STARTSUB counter initialization, GOPROG3 phase agreement checking, and positive Type C variable JOB admission through the original RESTARTS/ENDFIND or BAILOUT boundary. Its views gather seven-core Executive state, WAITLIST, protected phase records and restart/interface words. Alarm history and VAC payloads remain intact. Native scheduler alarm markers clear at cleanup; no suspended C frame is resumed.

CM cleanup has different behavior from LM: STARTSB2 preserves TIME3/4/5; STARTSUB resets those counters and DNTMGOTO. Cleanup uses CM dummy task 05306/04063, clears seven core priorities and five VAC occupancy markers, retains the last display word and EXTVBACT bit14, sets SKIPVHF, and models channel13 trap writes/readback. Type C restart preserves CM scratch words PHS2CADR=03755 and SWRETURN=04675 and CM NOVAC/FINDVAC addresses 05134/05147. Corrected priorities, source phase groups, resource alarms and no-VAC mutations are checked before publication.

The independent host-only GPL yaAGC oracle executes original CM source. All 1,280 checkpoints match status and every one of 429 owned words: 256 STARTSB2, 256 STARTSUB, 256 phase-check and 512 variable-job cases. Sixteen unrelated guards are checked. Snapshot SHA256 is `c58603b83c63fb2158a17efe4a643b30d63e0e35c05579ed0c447ce9304ea9e9`. Native code contains neither source interpreter nor rope.

`tools/cm_services_prepare_reference.py` uses pinned Virtual AGC commit `1b5d6474841a7ab53237ead070f76f35f162f68d` and overlays original repository CM Executive, WAITLIST, interrupt, phase, restart and fresh-start files. Byte-identical originals and explicit indentation patches are retained. Repairs are five Executive, nine WAITLIST and two fresh-start pseudo-label lines; interrupt, phase and RESTARTS need none. The complete normalized rope must equal an independent assembly of pinned corrected sources, SHA256 `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`. Original restart SHA256 is `490811f02cb07b69e98d9c558ed156f82e95d8735f29827edf8fe2fd6366efcc`; original fresh-start SHA256 is `d208d482531e01c2ffe48fca059117220d922c750b3936f0a046e9ea9499ae59`, normalized `29fc1df77ee162532c2b2038df72c24095f76463c87873e60b83ee477c1c0dda`. Historical sources are untouched.

Host and ASan/UBSan pass all 1,280 frozen source fingerprints, 18 full states and rejection checks. Stock PAL C64 passes those same 1,280 fingerprints and 18 full samples: mailbox `a500000005`, PRG 32824 bytes, text 12107, rodata 20703, BSS 859, final noinit end `$8b93`. Measured sentinel extents are 26 hardware-stack and 37 software-stack bytes; no extra zero-page spill sections. These measurements cover this bounded diagnostic, not a whole-program memory claim.

This foundation stops before MMDSPLAY/STOPRATE, DOFSTART and arbitrary restart-selected flight continuations. Type A/B and variable task/long-call execution, alarm recording/recovery and final native callback dispatch require separate modules and source proof. The API rejects unsupported phases or malformed source addresses without mutation; source-defined resource-alarm mutations are retained.
