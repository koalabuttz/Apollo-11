# Luminary canonical WAITLIST insertion

`lm_waitlist_image` translates literal WAITLIST05203 and TWIDDLE05173 through the actual caller return or source alarm entry. It inserts the explicit compiled task into the sole 2048-word image and preserves every original raw CPU/bank/list/scratch word. WAITLIST returns at Q+2; TWIDDLE returns at Q+1 and obtains the minor bank word from the actual caller BBANK and SUPER. Source interrupt inhibition remains until the caller's following RELINT. No task body, interrupt delivery, Executive poll or recovery executes here.

The verified native list algorithm owns insertion/time update. The canonical bridge derives the original WAITEXIT/WAITBANK/WAITADR/WAITTEMP and all source register debris, including discarded descriptor words and the path that detects a full list before insertion. A full insertion may already displace the last task: the source does not roll it back. Error1203 stops before BAILOUT1(05716); zero/negative delay error1204 stops before POODOO1(05726). Both retain actual raw caller/control state and the inline alarm descriptor remains unexecuted. Initialized ordinary image/list words, coherent source banks/SUPER, index zero, canonical A without overflow, a compiled valid task descriptor and legal inline caller Q are required. Documented positive delays above16250cs are rejected before mutation. Caller excludes source producers throughout this basic service.

All16,384 complete original-source, strict-native and ASAN/UBSAN states match: every2048 erasable word plus SUPER and source IRQ. The corpus includes both entries, insertion order, all0..9 occupied-task counts, varied pending/normal TIME3 phases, equal/signed-zero interval behavior, both errors, allbank/SUPER values and unchanged scratch. These are varied contexts rather than an exhaustive Cartesian product. Decoded SHA256 is `2b5fdf2322cb20c8e8917d23f775a24dfaeeef7743d7a003e1f2b06986f24ffb`. Seventeen invalid domains and two null interfaces preserve all state.

Actual stock-ROM PAL C64/D81 passes64 complete frozen source states using the resident bridge and32 fixed-slot input/check fixture modules, which return before the bridge executes. Mailbox`a50000400002`; measured software/hardware stacks158/31bytes; compiler ZP0. IDs160..191 belong to this isolated diagnostic and reserve no production mapping. The fixture source WAITLIST file is byte-identical to the historical Luminary source.
