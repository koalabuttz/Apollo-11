# Comanche 055 startup and phase cleanup

The MIT `cm_startup` executes original CM SLAP1 or DOFSTART initialization against the sole canonical image through ENDRSTRT, and MR.KLEAN/P00KLEAN/V37KLEAN through their TC Q return. Source-selected later flight and display continuations remain explicit caller work. No AGC rope, decoder or suspended native C frame is retained.

SLAP1 performs STARTSUB initialization, records a requested fresh start, clears failure/restart counters and initializes DSRUPTSW. DOFSTART zeros RCS output channels5/6, channels11..14 and source interface fields, restores coarse alignment when DSPTAB requires it, clears all six protected phase pairs, initializes mode/IMU/optics/T5 settings and source flag words while preserving NODOP01, REFSMMAT and Moon/surface flags. CM TERM and flag addresses are derived from original erasable assignments. CM P00KLEAN clears groups4 and1 before V37KLEAN; CM V37KLEAN itself clears only groups3,5,6. MR.KLEAN additionally clears group2 and inhibits interrupts. These differences were checked against CM source directly.

The independent host-only GPL oracle executes original FRESH_START_AND_RESTART source from the audited CM fixture, pinned Virtual AGC commit `1b5d6474841a7ab53237ead070f76f35f162f68d`. Original copies, two fresh-start pseudo-label indentation repairs and whole-rope reconciliation are retained in `evidence/cm-services-*` and described in COMANCHE_RESTART.md. Rope SHA256 is `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`; historical sources are untouched.

All 640 cases compare every2047 canonical image/register word except Z, plus15 explicit external-I/O values and status:2063 values per checkpoint. There are128 cases per entry, exercising coarse-align flags, all SUPERBNK encodings, both interrupt states, trap latches and nonzero erasable payloads. A/L are compared as raw16-bit register representations. Z is excluded because native execution uses explicit C boundaries, not an AGC instruction counter. The scaler is frozen and peripheral drive counters0035/0036/0047/0050..0054 are held atzero in independent inputs to prevent autonomous peripheral output from altering the oracle's image; no original flightword result is normalized. Snapshot SHA256 is `663782ee79df657ba2ab0038cee83c740e1f2eba31aa638610689fe68f173ebd`.

Stock PAL C64 passes those same640 fingerprints and five full vectors: mailbox `a500008002`, PRG35149 bytes, text11760, rodata23375, BSS4126, final noinit end `$a16b`. Stack sentinel extents are27 hardware and887 software bytes; no extra zero-page sections. This diagnostic uses a local image; application placement follows the established `$7000..7fff` image and resident overlay contract. Its measured stack fits the reserved2048-byte application software-stack region, but these measurements do not establish whole-application fit or WCET.

The required source entry bank is CM fixedbank5/erasablebank3. External channel5/6 latches have their own `cm_startup_ports`; channels11..14, traps and processor I/O use `cm_native_io`. Production callers own source exclusion and valid ordinary15-bit flightwords, with raw A/L handled separately. END RSTRT postjump, idle entry, arbitrary flight programs and major-mode display requests are outside this initialization boundary.
