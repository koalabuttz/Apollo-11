# Comanche 055 WAITLIST and native task boundary

The separate MIT `cm_waitlist` owns TIME3, eight interval words, nine two-word task addresses, RUPTAGN and the native alarm marker: 29 words / 58 bytes. Its translated insertion, T3 interrupt list update and TASKOVER operations use seven-core Comanche job state only through callers; its typed task runtime references the queue and holds no second copy of its word image. Raw primitives require caller exclusion. Task C frames finish before TASKOVER selects another task.

Original CM WAITLIST uses an early CCS delay test. Both signed zero encodings and negative delays reach POODOO (05721), alarm 01204, before WAITEXIT, WAITBANK, WAITADR or WAITTEMP is changed. Full queue paths reach BAILOUT (07755), alarm 01203. One full-list path detects the failure after insertion has displaced the final task; the native operation preserves those mutations. The built-in dummy task is CM SVCT3 at 05306 / 04063, derived from ENDTASK's actual negative 2CADR words. Its IMU housekeeping body is outside this queue boundary. Positive delays beyond the documented 16250-centisecond range, malformed addresses, unknown mappings and ambiguous counted timer overflow windows fail closed.

`tools/cm_waitlist_prepare_reference.py` creates an ignored fixture from Virtual AGC commit `1b5d6474841a7ab53237ead070f76f35f162f68d`, overlaid with this repository's original CM Executive, WAITLIST and interrupt lead-ins. Five Executive and nine WAITLIST pseudo-label lines require indentation repairs for yaYUL; the lead-ins need no repair. Byte-identical originals, explicit patches and hashes are retained in the fixture and evidence. It independently assembles the pinned corrected versions and requires equality of the complete ropes, SHA256 `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`. Historical sources are untouched. The GPL yaAGC oracle is host-only; it links neither native arithmetic nor native scheduling implementations.

All 196 constructed cases / 306 checkpoints agree exactly with original assembly on every owned word, result and transferred task address. Cases exercise insertion at all nine positions, equal deadlines, full-list mutations, both zero interval encodings, TIME3 pending overflow, alarm paths, explicit PINC counter steps, actual fixed-fixed T3 lead-in, TASKOVER bank restoration, and ten sequential native callback task sequences. The source oracle checks 16 unrelated guard words and actual BBANK/SUPERBNK transfers; bad delay checks additionally prove all four WAIT scratch words unchanged. Snapshot SHA256 is `c86bbfdf4adbda35033eb88783c81a64124dcbb6fd2c0cafa9fde4447693c924` (the authoritative hash is generated in the differential log).

Host and ASan/UBSan pass, including restoring nested exclusion hooks, callback reentry rejection, typed task mapping checks, latched helper faults, and counted clock publication/overflow preservation. The stock PAL C64 diagnostic compares all 32 assembly-derived result/state/transfer words at every one of the 306 checkpoints, including ten actual native task sequences. Its mailbox is `a500003201`; PRG size 33852 bytes, text 14057, rodata 19781, final noinit end `$8c76`. Measured sentinel extents are 36 hardware-stack bytes below `$01f2` and 89 software-stack bytes below `$d000`. No extra zero-page spill sections are allocated. This diagnostic alone does not install a hardware timer; the IRQ binding is tested separately. These measurements establish this bounded diagnostic's resource use, not whole-application fit or WCET.

Reproduce with `make cm-waitlist-differential`, `python3 tools/cm_freeze_waitlist.py`, `make test-cm-waitlist sanitize-cm-waitlist c64-cm-waitlist` and `python3 tools/cm_waitlist_vice_test.py --vice /path/to/x64sc --rom-dir /path/to/C64 --data-dir /path/to/vice`. Before the parent Makefile includes `tools/cm_waitlist.mk`, add `-f Makefile -f tools/cm_waitlist.mk` to make invocations. ASan leak scanning is disabled because this container blocks its ptrace workflow. Evidence is `evidence/cm-waitlist-*`, with generated hashes in `build/cm-waitlist-evidence.sha256`.
