# Luminary canonical Executive admission

`lm_admission_image` implements literal NOVAC (05072), FINDVAC (05105), SPVAC (05116), and SPVACIN (05112) through the actual caller return or resource-alarm entry. It binds the verified eight-core/five-VAC Executive service to the sole 2048-word erasable image, preserving all source register, bank, scratch, resource, and pending-job words. Successful admission returns at Q+2, with Q06743 and the original source EXECTEM1/2 and old core bank in L. SPVAC adjusts its incoming Q by minus two; SPVACIN does not.

The caller supplies NOVAC/FINDVAC's already compiled inline address pair. SPVAC/SPVACIN use canonical A/L and NEWPRIO. This is a C ABI translation of four known source entries, with no instruction decoder. Source interrupt inhibition is retained through the caller-return boundary; the caller's following RELINT is external. No native request poll, lifecycle exchange, admitted job body, BAILOUT body, or recovery runs here. Source resource exhaustion stops before BAILOUT1 (05716), retaining the source 1201/1202 descriptor and raw CPU debris.

The supported initialized Executive contract requires coherent banks and SUPER, ordinary packed priorities 01000..037000, nonzero positive/sleeping active priorities or minus-zero free slots, coherent VAC use markers, and a valid NEWJOB core offset or minus zero. Idle core zero requires NEWJOB minus zero. The incoming index is zero and caller Q permits its inline pair and source return. SPVAC entries already have source interrupts disabled. Priority plus zero and inconsistent idle NEWJOB states are rejected: those source paths execute embedded data or call the separate CCSHOLE service. Caller owns all source producers throughout this bounded basic service.

All 16,384 complete original-source, strict-native, and ASAN/UBSAN states match: the complete 2048-word image plus SUPER and source IRQ, covering all four entries, eight first-free core slots or a full pool, five VAC slots or a full pool, all ordinary priorities, varied banks/SUPER, admitted descriptors and unchanged memory. Decoded SHA256 is `578771084570f6c3bf9c849443105d0307385cfe7c3b02ee551ac27e4e7a0ffe`. The contexts are varied rather than an exhaustive Cartesian product. Twenty-two invalid domains and two null interfaces preserve all input state.

The actual stock-ROM PAL C64 test passes 64 complete frozen source states using a resident service and 32 fixed-slot disk fixture modules. Each fixture returns before the service executes, then reloads to compare every output word. Mailbox is `a50000400002`; software and hardware stack extents are 752 and 30 bytes, with zero compiler zero-page allocation. Fixture IDs160..191 belong only to this isolated diagnostic disk and reserve no production IDs.

Run `make -f tools/lm_admission_image.mk test sanitize` for clean host comparisons against the retained original XZ stream. `reference` regenerates the independent original-engine oracle; `c64 vice-test` uses MOS_CC, C1541, VICE, C64_ROM_DIR, and VICE_DATA_DIR. The containing EXECUTIVE source file has additional services; this packet qualifies these four entries and their shared admission paths, not complete Executive or application coverage.
