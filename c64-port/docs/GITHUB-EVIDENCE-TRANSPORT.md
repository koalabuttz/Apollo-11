# GitHub evidence transport

Two frozen Comanche Executive gzip streams exceed GitHub100MiB limits. Local history and proof identities retain those original bytes. Publication represents their compressed bytes in48MiB parts and restores them at the same evidence paths before Make targets run. Native/reference aliases reconstruct exactly, checked in an isolated temporary checkout. The original ledgers, numerical corpora and C64 outputs remain unchanged.

Affected unpublished milestones use remote transport trees, recorded alongside their original local tree hashes. Earlier exact-tree publications remain untouched. Use the audited publication helper, since direct local push includes the oversized historical blobs. `python3 tools/restore_github_evidence.py --verify` checks restored archives explicitly. Whole applications remain open.
