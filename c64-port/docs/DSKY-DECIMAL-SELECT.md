It imports the complemented current XREG component, clears MPAC's lower limbs, selects the source display row, computes the original normal or mixed factor number, calls the immutable mission-specific GTSFOUT table reader, then performs the original routine-number extraction and BANKJUMP effects. The canonical image retains all SFCONUM/SFRUT editing, EXITEM, A/L/Q and bank debris. Factors come from the actual mission table; component data stays in caller-owned canonical RAM.

The bounded domain is DECOUNT0..2, MIXBR1/2, source routine0..13, a factor pair within the actual mission SFOUTAB (LM0..28, CM0..19), ordinary RAM/raw16 A/L/Q, coherent bank41/anyEB, selecting SUPER100/120/140/160 and legal IRQ. Both immutable mission tables must be linked. Caller excludes producers; unsupported image/IO/route is unchanged. The returned routine index identifies the source-selected continuation. This stage does not execute that scale body, a formatter, instruction words or an additional scheduler check.

The mission differences are explicit: code6 selects LM LRPOSOUT or CM OPDEGOUT; code13 selects LM360-CDUO or CM DPFRACOT. Code8 and9 select the actual HMSOUT/M/SOUT bank42 bodies. All other source CADR data and the distinct RIGHT5/LEFT5 displacement words are retained exactly.
