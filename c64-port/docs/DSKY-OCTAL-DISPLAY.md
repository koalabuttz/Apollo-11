# Native octal display services

`dsky_octal_display` and `cm_octal_display` execute actual original
DSPOCTWD/DSPOCTWO41,3363 and DSP2BIT41,3416, through source ordinary caller
return or genuine selected positive-zero CCSHOLE handoff. Five-character
output blanks the sign; two-character output preserves the source editing
register rotations. CYL/CYR, raw CPU registers, WDRET, WDCNT, display scratch,
relay dirty markers and overflow-corrected NOUT remain original word effects.
The code composes the unchanged native DSPIN stores with a temporary physical
bank40 view; authoritative SUPER retains its actual100/120/140/160 latch.

Inputs require ordinary sign-extended A, ordinary Q0100..7777, canonical
ordinary words, FB062000, any aligned EB and IRQ0/1. DSPCOUNT accepts4..21
for five characters and1..21 for two. Unused clean positive-zero relay words
are accepted. A selected positive-zero word executes the real DSPIN prelude
and stops at LMCCSHOLE05705 or CMCCSHOLE05747, preserving incoming source
Q, scratch, banks and inhibited IRQ. This is an explicit exceptional recovery
handoff, not a fabricated return. Invalid inputs leave image, I/O and route
unchanged. The caller holds restoring producer exclusion across composition.
