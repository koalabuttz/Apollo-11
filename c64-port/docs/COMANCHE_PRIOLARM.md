# Comanche priority alarm entry

`cm_priolarm` translates actual Comanche055 PRIOLARM10,3766 through PRIOENT+1 to the genuine PRIODSPR10,2726 display entry or MULTFAIL overflow POODOO05721 entry. It executes native C over the sole canonical 2048-word image; no instruction decoder or original executable engine is linked into native/target code.

The actual `TS L` overflow skip matters: ordinary A saves the caller BUF2 word in ALMCADR, whereas positive/negative overflow leaves the original +1/-1 descriptor there. ALMCADR+1 preserves saved BUF2+1 OR SUPERBNK. Source FAILREG allocation, full-register L exchanges, lamp/ITEMP effects, Q3774/5715, and interrupt latch are retained. The normal display A is actual V05N09 raw01211. Downstream display admission and abort recovery are separate continuations. No successful saved-caller return is invented for overflow descriptors.

Fresh original-layout Comanche rope SHA256 `6e3150ae9b43535237e10f565205d1f65e6d60cafbe8935be598e03e9810b061` is verified against the retained byte-original rope. All 65,536 raw A16 and incoming Q16 values, eight erasable banks, eight SUPER values, incoming IRQ contexts, caller BBCON choices and source FAILREG corner cohorts produce exactly matching complete 2048-word +13-I/O records. The binary stream is 270,663,680 bytes, SHA256 `fe216e60aa5c53c34c6be48a9028ca2e9881cd35004a565ceae4d28ef7437abb`. Strict host and the entire ASAN/UBSAN corpus pass. Incoming Q is overwritten by the real source TC; other eleven external latches are preserved, not interpreted as erasable memory.

Stock PAL C64 executes 32 source-derived cases with both incoming hardware I states and original ROM mapping restored. Each target result compares a complete-state FNV against the original source, two complete 2061-word samples compare directly, and the final 2048-word image is captured and compared externally. Mailbox `a500002000`; measured resident software stack708 bytes. Native module225 is1699 loaded bytes, factory2544725, checker2559725. Overlays swap only after prior C frames return; producer exclusion spans each load/call. Scratch metadata is bounded atc000 and I/O atc400; canonical image remains7000..7fff.

Run `make -f Makefile -f tools/cm_priolarm.mk test-cm-priolarm` and `sanitize-cm-priolarm`. Freeze/build/VICE scripts are retained with exact source and target artifacts. This is a bounded actual entry qualification; ALARM_AND_ABORT and DISPLAY_INTERFACE_ROUTINES whole-file qualification remain false until their remaining paths and real producer/consumer domains close.
