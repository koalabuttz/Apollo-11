# Translate Luminary P12

Lane F (LM powered flight and DAP). Milestone `lm-p12`. How the routines are made and checked: `docs/INTERP-COMPILE.md`.

`Luminary099/P12.agc` (`src/lm_p12.c`, generated by `tools/interp_compile.py lm-p12`) is native C, every word of it. P12 is the powered ascent program: it checks the IMU, sets the ascent flags, initializes the engine and target data (P12INIT, COMMINIT, GUIDINIT, also used by P70 and P71), advances the state to ignition, flashes TIG and the cross-range display, and sets up the tip-over velocity before going to ASCENT; P12RET then computes the yaw and pitch and goes to BURNBABY.

## Scope

| Luminary099 | Source | Leaves at |
|---|---|---|
| 30,2061 P12LM to 30,2320 | P12LM, P12LMB, NEWLOAD, P12RET, YAWDUN, P12INIT, COMMINIT | PHASCHNG, BANKCALL (R02BOTH, GOFLASH with its three returns), IBNKCALL (PFLITEDB), UPFLAG, DOWNFLAG, CLRADMOD, GOTOPOOH, POSTJUMP BURNBABY, CALL LEMPREC, MUNGRAV, YCOMP |
| 23,2432 GUIDINIT to 23,2460 | GUIDINIT | RTB LOADTIME (native, `src/rtb_angles.c`), CALL RP-TO-R, the caller's return through TEMPR60 |

91 routines start at the entries (P12LM, P12LMB, P12RET, P12INIT, COMMINIT, GUIDINIT), at every point another file returns to (BANKCALL, PHASCHNG and the display returns), at words nothing in the file reaches (`resume_orphans`), and at every word after a DANZIG (`resume_keys`): P12 runs as a job, so a DANZIG can find a job waiting and stop at CHANG2, and the Executive resumes the job there.

NEWJOB positive at a DANZIG is not a refusal: the run stops at CHANG2, as the original does, and that stop is compared with yaAGC; the word after it is a registered key.

## Evidence

Hashes: `evidence/lm-p12/SHA256.json`.

- **Source map.** `lm-p12-source-map.json` lists all 183 words with the routine that compiles each; none is untranslated.
- **Independent assembly comparison.** `make lm-p12-differential`: 512 states for each of the 91 routines (46,592 cases, with the flight edge values of `tools/edge_cases.py` in a quarter) run the unmodified Luminary099 rope in yaAGC (with the hardware divide) to the same stop. All 46,592 equal it in Z, all 2,048 erasable words and the interrupt-enable state; none is refused.
- **Host and sanitizer results.** `make test-lm-p12 sanitize-lm-p12` run the 1,456 frozen cases (every 32nd).
- **C64 execution results.** `make vice-lm-p12` runs 7 diagnostics (routine groups that fit below $bf00) with 110 cases chosen by `tools/c64_row_cover.py`: together they take all 1,024 branch arcs (gcov, every linked source) that the 46,592 host cases take (`lm-p12-c64-cover.json`).
