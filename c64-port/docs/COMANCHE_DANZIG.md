# Comanche 055 canonical DANZIG and job handoff

`cm_danzig` translates actual interpreter DANZIG06030 through NEWOPS06037 for the current interpreted job, or CHANG2/CHANJOB/ENDPRCHG and the actual selected basic or interpreted continuation. All 2048 canonical physical words, raw A/L/Q, SUPERBNK, IRQ, channel11 and selected context type/address are checked against original assembly. Source BANKSET first restores physical BBANK before the NEWJOB test. EDOP must be zero; a pending order opcode is outside this compiled boundary and is never decoded.

NEWJOB +0 advances LOC and resumes NEWOPS. A positive admitted displacement selects one of the six waiting contexts, preserving the outgoing complemented completed LOC and BBCON in the original saved core. Selected interpreted contexts resume at complement(savedLOC)+1 via INTRSM. The source CHANG2 uses CAF EXECBANK / TS BBANK: its CADR literal02626 sets physical EB6, so the eventual DTCB/INTRSM L debris is02006. This differs from ENDOFJOB's FBANK-only preparation and was independently resolved from the full original state proof.

The public qualified domain requires PC06030, EDOP +0, valid physical BANKSET, ordinary positive current LOC and priority, valid positive selected candidate priority/LOC/BBCON, and NEWJOB +0 or a valid nonzero displacement. NEWJOB -0 is rejected: the original CCS branch skips directly past NEWOPS's INDEX LOC, and is not the ordinary active interpreter state. Unsupported guards preserve the image and external I/O. Raw Q is retained exactly. Counters are zero and the source scaler is frozen. This helper executes no application payload or decoder.
