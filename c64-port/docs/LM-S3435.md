# S34/35 line-of-sight subroutines: S34/35.1, S34/35.4, NOVRWRT, LOMAT

Lane E. Milestone `lm-s3435`.

## Scope

From `Luminary099/P34-35_P74-75.agc`, bank 35 `03274`-`03305` and
`03424`-`03461`: 40 words on 40 source lines. Four interpretive routines of
the control-transfer ABI (`include/agc_transfer.h`,
`docs/NATIVE_TRANSFER_ABI.md`) are keyed by LOC under BANKSET at NEWOPS:

- **S34/35.1 (`35,3274`):** computes the unit line of sight
  ULOS = UNIT(RPASS3 - RACT3) and the orbit normal UNRM = UNIT(RACT3 x
  VACT3), then RVQ.
- **S34/35.4 (`35,3442`):** STQ NORMEX, SETPD 0D, then GOTO NOVRWRT.
- **NOVRWRT (`35,3424`):** pushes the line-of-sight frame onto the push-down
  list: ULOS, UNIT(UNRM x ULOS), and that unit vector x ULOS. It then rotates
  DELVEET3 through the matrix at 0D (MXV) into DVLOS, and ends with STCALL
  DVLOS to the CADR in NORMEX.
- **LOMAT (`35,3447`):** builds the local-vertical matrix at 0D-17D (-UNRM,
  -UNIT(RACT3), and their cross product), then SETPD 18D and RVQ.

S34/35.4's GOTO reaches NOVRWRT's NEWOPS, so the trampoline runs both
routines in turn. Each run ends at the first NEWOPS outside the routines: the
caller's return at C(QPRET), or the CADR in NORMEX. UNIT's alarm (POODOO1,
1302) would also end a run, but no sampled entry reaches it.

Every interpretive pair is compiled with the shared bodies
(`src/lm_interp_steps.c`, `src/lm_interp_orders.c`). MXV runs the compiled
matrix phases (`src/matrix_native.c`) on the work-area matrix, with the
ADDRWD bias that lm-midgim's GET.LVC uses.

Routines admit a canonical NEWOPS image at their LOC in FB 35 meeting all of
these conditions, and otherwise return `EXEC_OUT_OF_SCOPE` with the image
unchanged:

- EB and BB coherent, with BANKSET = BB;
- INTBIT15 set;
- EDOP, ZERO and NEWJOB zero;
- MODE `+0`, `+1` or vector;
- the VAC one of the five, with PUSHLOC inside it;
- IRQ 0 or 1, and an allowed SUPERBNK;
- every word 15 bits.

## Evidence

Hashes are in `evidence/lm-s3435/SHA256.json`. Bulk files are assets of the
`evidence-lm-s3435` release (`python3 tools/evidence.py fetch lm-s3435`).

- **Source-to-native map and independent assembly comparison.**
  `python3 tools/lm_s3435_source.py` reassembles the unchanged file with the
  pinned yaYUL. The rope equals the certified fixed-data rope.
- **Oracle.** `tools/lm_s3435_reference.c` (GPL, host only) runs the unchanged
  Luminary099 in the pinned yaAGC hardware-DV variant from 16384 entries,
  4096 per routine. It stops at the first NEWOPS outside the routines, or at
  POODOO1.
  - The entries sit over poisoned debris with any vectors. One state in eight
    has the vector UNIT reads zero or nearly so.
  - They cover every VAC, PUSHLOC, MODE, IRQ and allowed SUPERBNK setting.
  - QPRET (or NORMEX for NOVRWRT) is one of the routine's real callers'
    returns (`35,2754`, `3006`, `3572`, `3600`, `3371`, `3402`), or a CADR in
    banks 2-27.

  `tools/lm_s3435_differential.py` requires every native trampoline run to
  produce the same 2048 erasable words, interrupt state and SUPERBNK. It pins
  the stream identity (`lm-s3435-source-stream.json`, SHA256
  `ebe6398e...26cced`) and archives the stream
  (`lm-s3435-reference.snapshots.bin.xz`). `lm-s3435-proof.json` lists the
  stops per routine.
- **Host and sanitizer results.** Run `make test-lm-s3435 sanitize-lm-s3435`.
  The strict build and the ASAN/UBSAN build each pass 16442 checks:
  - all 16384 frozen digests;
  - every run ending at a NEWOPS outside the routines;
  - 52 admission guards (EB, BB, ZERO, 16-bit words, SUPERBNK, IRQ, VAC,
    MODE, INTBIT15, EDOP, NEWJOB, BANKSET and PUSHLOC for each routine).

  See `lm-s3435-checks.log`.
- **C64 execution results.** Run `make lm-s3435-vice`
  (vice-lm-s3435-1 and -2 on CI, one per group). Two PRGs each register
  only the routines their cases reach: S34/35.1 and LOMAT in one, NOVRWRT and
  S34/35.4 in the other. Both keep the image in the RAM under KERNAL ROM
  (`$01=$35`). The case generator is integer-only, so the C64 builds the same
  entry images as the host. In VICE (PAL, stock ROMs) each PRG passes 512
  checks with no failures (`lm-s3435-results.json`).

## Limits

- S34/35.3 and GOINT/INTINT are lm-s3435b (`docs/LM-S3435B.md`); S34/35.2's
  integration head and S34/35.5 are in the whole-file lm-p34-p35 (`docs/LM-P34-P35.md`).
  S34/35.2's ACOS and Lambert setup, ELCALC and P34/P35 themselves are not
  covered. The file stays `partial`.
- Numerical validity is the original's. No wider claim is made.
