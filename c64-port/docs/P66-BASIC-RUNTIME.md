# Compose real P66 basic jobs, task admission and display output

The native basic binding executes DSPMMJB and ENDJOB, admits RODTASK at its actual 100-centisecond WAITLIST interval, invokes the mapped RODCOMP job and routes DSPOUT to the C64 screen. The RODTASK source comparison covers 2048 complete states, sanitizer results and 64 C64 states; the final resident diagnostic passes eight complete source images with the corrected zero, alarm-width and shared-Executive dependencies. Full descent and interrupt composition remain separate milestones.

These bounded services do not certify complete program coverage. The original
Luminary and Comanche source trees remain unchanged. Public headers state each
entry domain and producer exclusions; evidence includes original-source states,
host and sanitizer results, target PRGs, maps, mailboxes and stack measurements.

Reproduce the source comparison with `python3 tools/p66_basic_differential.py deps/fixture`.
