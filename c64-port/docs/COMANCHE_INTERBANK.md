# Comanche native interbank communication

`cm_interbank` translates every executable control group in original INTER-BANK_COMMUNICATION.agc: BANKCALL/SWCALL/SWRETURN, POSTJUMP/BANKJUMP, MAKECADR, SUPDACAL, IBNKCALL/ISWCALL/ISWRETRN, USPRCADR, SUPERSW and the explicit Q+10000/PRIO12 continuation entries. The canonical 2048 physical erasable words and explicit SUPERBNK/IRQ remain authoritative. The API accepts a compiled inline CADR literal where the historical caller supplied one; no source instruction word is fetched or decoded.

BANKCALL uses source BUF2 at0133/0134; interrupt calls use RUPTREG3/4 at0072/0073. Calls preserve incoming A/L, save the actual return pair, switch FBANK and set the genuine SWRETURN/ISWRETRN Q. Returns preserve A/L and retain the original bank debris and final Q0134 or0073. MAKECADR/SUPDACAL/SUPERSW perform the original TC Q return, including its raw Q=3 effect. USPRCADR saves the caller LOC/BANKSET and EDOP's edited EXIT value1 before transferring to the actual interpreted bank/subaddress. Producer exclusion is caller-owned.

SUPDACAL reads only the independently certified immutable spans exposed by fixed_data. It applies the real superbank physical mapping, preserves the original FBANK/SUPERBNK, stores the fetched word in MPTEMP0135, retains the relative data address in L and enables IRQ on return. All100 original CM NNTYPTAB words are exercised directly in this interbank source proof. Other certified data spans retain the separate full-original-data qualification; unsupported addresses preserve the image/I/O. The supporting fixture retains documented pinned ALTVAR/R53FLBIT assignments; NNTYPTAB and the control groups use neither differing definition.

The qualified CPU entry domain has a consistent ordinary physical bank pair, source PC for the explicit entry, no pending index/extension, ordinary non-overflowing A, ordinary saved Q0..07775 and valid source return descriptors. Each operation ends at its actual selected source target/return; executing that application's next callback belongs to the resident dispatcher. The API never executes the TC instruction stored in a return buffer: it performs the known compiled return semantics and publishes the actual address. Raw A/L/Q outputs, every physical word and SUPER/IRQ are compared without normalization.

Original interbank SHA25642f815caec6cba78fa7a084186d25cbd5bd1a576e7b9e149e429cf3e886b0785 is byte-identical in the fixture, with zero transcription repairs. Pinned VirtualAGC1b5d6474841a7ab53237ead070f76f35f162f68d supplies a host-only oracle; complete rope SHA2562ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79 equals the supporting baseline. Counter driver words are zero and the source scaler is frozen.

All7168 original/native complete2051-value states match SHA25624ccdc52b0a11ec6fba29668131e2f8763e32b86fe015aa876adcbbe3f46211f. Strict host and ASAN/UBSAN pass all14 entry cohorts. Stock PAL C64 passes112 representative full-state fingerprints and two complete samples, mailboxa500007000; measured hardware/software stack extents10/93bytes. Tests cover every control entry, all physical bank/EB/superbank domains, positive/negative A/L and every selected noun-type data word. No whole-application completion or WCET claim is made.

Reproduce with tools/cm_interbank.mk differential/test/sanitize/C64 targets. tools/cm_interbank_report.py freezes exact code, source and target artifacts. Native implementation is MIT; the original assembly engine is GPL host-only.
