# Translate Luminary P70-P71

Lane F (LM powered flight and DAP). Milestone `lm-p70-p71`. How the routines are made and checked: `docs/INTERP-COMPILE.md`.

`Luminary099/P70-P71.agc` (`src/lm_p70_p71.c`, generated by `tools/interp_compile.py lm-p70-p71`) is native C except for the words that use I/O channels. The file holds the descent abort programs P70 (DPS abort) and P71 (APS abort), the abort-switch task R10,R11 that flashes the landing displays and starts an abort, the abort job set-up (CONTABRT, ABRTJASK), the abort initialization (GOABORT, P70INIT, INJTARG, BOTHPOLY, UPRATE, UPTHROT), P71RET, TGOCOMP and THROTUP.

## Scope

| Luminary099 | Source | Leaves at |
|---|---|---|
| 21,2006 R10,R11 to 21,2127 | R10,R11, R10,R11A, FLASHH?, FLASHV?, P70, P70A, P71, P71A, LEGAL? | TASKOVER, LRHTASK, TWIDDLE, FLIP, TCF LANDISP, CLRADMOD, FALTON, RELDSP, CHECKMM, POSTJUMP |
| 05,3402 CONTABRT to 05,3501 | CONTABRT, ABRTJASK | PHASCHNG, DOWNFLAG, UPFLAG, BANKCALL, ENDOFJOB, POSTJUMP |
| 32,3540 GOABORT to 32,3767 | GOABORT, P70INIT, INJTARG, BOTHPOLY, UPRATE, YOK, UPTHROT, UPTHROT1, P71RET, OLDTIME, TGOCOMP, THROTUP | as above, RTB LOADTIME (native, `src/rtb_angles.c`), the P12 set-up (P12INIT, COMMINIT, GUIDINIT) |

88 routines start at the entries, at every point another file returns to (BANKCALL, PHASCHNG and the display returns), at words nothing in the file reaches (`resume_orphans`) and at every word after a DANZIG (`resume_keys`).

ABRTJASK's `INDEX Q; CAF MODE70` reads MODE70 or MODE71 with Q -0 (P70) or 2 (P71): the spec's `basic_fixed_index` lists those two. BOTHPOLY reads the DPS or the APS coefficients at `ABTCOF,1` (erasable) with X1 -0 or -8, so its routines get those X1 values as generated states.

Not translated: the 8 words of the channel instructions, `READ CHAN30` (R10,R11A), `RAND`/`WRITE DSALMOUT` (ABRTJASK, the engine-off bits) and `WOR CHAN14` (THROTUP). They wait for the channel model in the control-transfer ABI (Lane D1's model takes the input channels first); the compiled routines stop with `EXEC_OUT_OF_SCOPE` at them, and the source map records them as untranslated with that reason. The file stays partial until they are translated, so no certificate is drafted yet.

## Compiler changes

`tools/interp_compile.py` gained what this file needs, and every earlier spec still regenerates byte-identical (`--check`):

- `DTCB` (`DXCH Z`: P70A and P71A's jump to CONTABRT in bank 05) sets Z and BB from A, L.
- `RESUME` (basic word 050017, in CONTABRT) runs the instruction CONTABRT put in BRUPT (`TCF ABRTJASK`).
- `INDEX` on a fixed operand, for the values the spec's `basic_fixed_index` lists (others refuse).
- `tools/interp_routine_differential.py`: with `'c64_rows': 'cover'`, the cases waiting for a channel are listed, not compared, so their branch arcs are no C64 row's to take; KEEP words are sized before the cover's trial builds.

## Evidence

Hashes: `evidence/lm-p70-p71/SHA256.json`.

- **Source map.** `lm-p70-p71-source-map.json` lists all 298 words with the routine that compiles each, or the reason it is not compiled (8 channel words).
- **Independent assembly comparison.** `make lm-p70-p71-differential`: 512 states for each of the 88 routines (45,056 cases, with the flight edge values of `tools/edge_cases.py` in a quarter) run the unmodified Luminary099 rope in yaAGC (with the hardware divide) to the same stop. All 37,747 compared cases equal it in Z, all 2,048 erasable words and the interrupt-enable state. The 7,309 cases that reach a channel instruction are listed in `lm-p70-p71-proof.json` as `waiting_for_io_channels` and are not compared.
- **Host and sanitizer results.** `make test-lm-p70-p71 sanitize-lm-p70-p71` run the 1,184 frozen cases.
- **C64 execution results.** `make vice-lm-p70-p71` runs 4 diagnostics with 101 cases chosen by `tools/c64_row_cover.py`: together they take all 854 branch arcs (gcov, every linked source) that the 37,747 compared host cases take (`lm-p70-p71-c64-cover.json`).
