# Comanche MYSUBS source coverage

The entire original Comanche055 MYSUBS source is mapped to native C: SMALLMP, DPADD and their fixed-code caller returns, plus four exact aliases to the already qualified SPCOS/SPSIN routines. All35 emitted basic source words are independently executed in the assembly corpus. Assembler BANK/SETLOC/EBANK/COUNT directives retain their binding/accounting roles; comments and the empty page emit no code.

| Original lines | Native mapping |
|---|---|
| 37–40 SPCOS1/SPCOS2/SPSIN1/SPSIN2 | Exact EQUALS aliases to fixed SPCOS05074 and SPSIN05075; `cm_single_trig` followed by `cm_single_return`, qualified by separate immutable numerical/return packages |
| 47–55 SMALLMP | `cm_smallmp`: source one-and-one-half precision product, KMPTEMP, retained intermediate AY, final DAS, raw A/L and overflow indicator |
| 56 TC Q | `cm_mysubs_return` from02053 |
| 63–77 DPADD / TSK | `cm_dpadd`: immediate raw pair sum, BZF no-overflow path, CCS distinctions among both signed zeros and positive/negative high and low words, final source stores |
| 80–91 DPADD+/DPADD-/DPADD2+ | `cm_dpadd`: source angle wrap for either overflow sign, including zero high word with each low-word sign |
| 78 TC Q | `cm_mysubs_return` from02073 |

The independently assembled original file has SHA256 `eed144c40c1ea8d938c4cced7906f12662f2e9df6d11ba551a869f5a6a038c84`, with no source or indentation edits. Its qualified full rope remains `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`. Although the source BANK directive says20, SETLOC places these entries in actual bank21. Native entries require FB042000, EB03000 and BB042006. Physical KMPAC high/low are03110/03111, KMPTEMP03112. SMALLMP enters21,2042 and stops before TC Q21,2053; DPADD enters21,2054 and stops before TC Q21,2073. Source POSMAX/NEGMAX are037777/040000.

The native arithmetic preserves two subtle original paths. An overflowing initial SMALLMP TS skips EXTEND, so the original unextended word at2044 performs MASK rather than multiplication; its compiled native alternate path preserves that behavior. DPADD begins immediately with DAS, so its first sum consumes a deliberately raw overflowing L before a prior instruction could correct it. Native pair arithmetic therefore uses raw L at that first boundary and preserves the original signed-zero/overflow carries. The source-defined raw behavior does not extend the historical physical angle scaling guarantee.

The independent original engine executes73,728 calls per arithmetic entry: every65,536 raw sixteen-bit A input, varying raw L, every ordinary KMPAC high/low value, all fixed saved-Q addresses02000..07777, and8,192 targeted signed-zero/limit/mixed-word edge combinations. Complete2048-word-plus-IRQ states are recorded immediately before TC Q and after its saved fixed-code return. All294,912 checkpoints from original assembly, strict native composition and whole ASAN/UBSAN execution are byte-identical: SHA256 `c58c2195e3a66cdde01a15e953d6b067facd1b957c3baf3e64fdaafcedebfe35`. Every unowned source word and MODE is compared. The original source trace records nonzero execution counts for every one of the35 emitted basic words, with first cases for each branch; those rare cases are included in the frozen target set.

Four actual C64 PRGs pass128 complete original states: numerical SMALLMP, numerical DPADD, and each routine composed with its final return. Maximum loaded end is$3c52, measured hardware/software stacks17/51 bytes, compiler-reserved zero-page use0. Frozen deltas reconstruct full source outputs from the qualified original input factory. Unsupported bank, PC and REGZERO states reject unchanged, with strict host checks of that contract.

The APIs require ordinary source Q<=07777 until the explicit return. The return accepts only the qualified bank21/E6 source-produced TC Q boundary and fixed-code saved return02000..07777; it preserves A, normalizes L, retains banks/IRQ, sets PC=savedQ and Q3. Synthetic erasable return code is outside the source caller domain. There is no Executive check inside these basic routines or their return: caller ownership of the canonical image and exclusion of input/scratch producers spans the whole call. IRQ is retained externally. Native code uses integer word arithmetic, with no AGC opcode decoder, host floating point or copied GPL instruction engine.

Reproduce the independent fixture with `python tools/cm_mysubs_prepare_reference.py`, using the immutable CM trig fixture prerequisite, and the pinned hardware-DV host reference prerequisite `python tools/prepare_hardware_dv.py`. Run `make -f tools/cm_mysubs.mk test sanitize check-host`; regenerate target fixtures with `python tools/freeze_cm_mysubs.py`. Corpus constructors stream through deterministic gzip, preventing large raw duplicates. The freezer accepts either the build compressed reference or committed compressed source corpus. The `c64`/`vice-test` targets accept SELECTOR0..3 (default0), MOS_CC, VICE, C64_ROM_DIR and VICE_DATA_DIR.

One exact compressed object serves original/native/sanitized logical output names. Source audit/listing, full corpus SHA, original branch trace, strict/sanitizer logs and actual target PRGs/maps/mailboxes/stacks are retained under `cm-mysubs-proof.json` and its manifest. The reviewed source-file certificate supports inventory integration. Complete resident Comanche/Luminary application boot, overlays, scheduling, devices and recovery remain separate acceptance work.
