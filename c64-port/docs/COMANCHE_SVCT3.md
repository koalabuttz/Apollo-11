# Comanche actual SVCT3 housekeeping

`cm_svct3_phase` translates the original housekeeping task rather than treating the WAITLIST ENDTASK descriptor as an automatic completion. Phase 0 executes SVCT3 at 05306, phase 1 its NOVAC return at 05323, and phase 2 the actual delayed recheck at 07721. Positive/+0 drift flags finish at TASKOVER; negative/-0 flags test IMUCADR. IMUCADR +0 admits the genuine NBDONLY job `(03542,014063)` at priority 035000; its other three CCS classes call FIXDELAY with the source literal 500 centiseconds and later recheck SVCT3. Each phase stops at the actual selected service, preserving the source raw registers, Q/PC/banks and sole canonical image. Service invocation and application-job execution belong to the resident loop.

All 1536 cases compare every 2048 physical word, external SUPERBNK/IRQ and status against original assembly, covering all 64 drift/IMUCADR signed-zero and magnitude corner combinations in both executing phases and poisoned register/image payloads. Host and ASan/UBSan pass all full-image fingerprints and two complete 2051-value states. Snapshot SHA256 is `5159630a0228428e720113fb2482c41bb5a95a14c5211b95370e720368721b68`. Counter-drive inputs are zero, the scaler is frozen, and no output is normalized. The GPL oracle runs only on the host at Virtual AGC `1b5d6474841a7ab53237ead070f76f35f162f68d`, with original WAITLIST and its nine audited indentation-only pseudo-label repairs plus pinned corrected supporting sources. Fixture rope SHA256 is `2ba31de9291cd10fb351a64d261bae8514a1cb75b4651bfa6a135dfa821a2d79`; historical originals are untouched.

PAL C64 passes 192 representative full-image fingerprints (64 per phase) and one complete 2051-value sample, mailbox `a50000c000`. PRG 16492 bytes, text 2110, rodata 14368, BSS 4122, image end `$5885`, hardware/software stack extents 10/9 bytes, no extra zero-page sections. Native code is MIT, with no executable rope or AGC decoder, duplicated persistent flight image or suspended overlay frame. Producer exclusion is caller-owned. This standalone proof does not establish whole-application fit, timing or completion of NBDONLY.
