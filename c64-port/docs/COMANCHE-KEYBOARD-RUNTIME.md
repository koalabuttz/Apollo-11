# Comanche keyboard job lifecycle

`cm_keyboard_runtime_entry` composes actual Comanche source stages through one canonical image and explicit cm_native_io. Selector1 executes the original vector4024→KEYRUPT/KEYCOM→NOVAC→RESUME. Selector2 executes actual idle ADVAN01,3231 and its genuine source-selected continuation. Selectors3/4 execute CHARIN40,2000 VERB/NOUN or NUM. Selector5 executes real ENDOFJOB5217 through the seven-core scan and selected basic/interpreted/idle continuation. Each C frame returns before another stage or disk module runs. Transfers are explicit positive source metadata; no opcode or BRUPT word becomes a C callback.

The independent complete lifecycle corpus starts with source idle core0 and available cores, a formed original keyboard ISR frame, and actual Pinball input fields. It restores the interrupted ADVAN entry, admits and selects real CHARIN2000/060101, formats the key and completes that job to actual idle3231. Other queued-slot/interpretive selections are supported by the separately source-qualified idle/completion bodies but are not widened into this complete-chain corpus. Device lock/lamp cases and raw-register signed zero are retained. State is not copied from an unrelated factory during execution.

Original assembly compares1024 complete lifecycles at four checkpoints each:4096 complete2056-field states, containing2048 physical words, SUPER/IRQ/channel11, ISR/event and actual transfer tuple/kind. The original output callback records real channel11 events rather than assuming that a key always writes a lamp. Full native/original SHA256:
`2859c8f76379988bd50ff1599ad8b4b59cb313f4cd59c5c204aaaf72563f29c4`.
The complete ASan/UBSan stream equals the original byte for byte. The oracle links no native bodies. Original CM KEYRUPT, interrupt lead-ins, Executive, Pinball, T4 and Interpreter bytes, indentation-only normalization and byte-identical pinned rope are recorded in build/cm-keyboard-runtime-source-audit.json.

Frozen8 complete lifecycles32 full source checkpoints pass strict host, sanitizer and native C64. The target places each actual key character into the C64 KERNAL buffer, calls real GETIN through the shared hardware transport, and feeds its channel15 code into the genuine CM ISR/job chain. VICE PAL mailbox `a500000804`; PRG25882 bytes (loaded25880); hardware/software stack16/760 bytes. RAM-section bounds and additional zero-page storage are checked. `tools/cm_keyboard_runtime.mk` supplies portable host-only all/test/sanitize and explicit C64/differential targets.

The caller owns source exclusion and formed interrupt entry metadata; this module does not install a C64 IRQ vector or emulate AGC instruction interrupts. A resident CM application must route these returned continuations alongside clock/restart/display jobs. Sign, clear, enter, reset and illegal-key bodies remain required translations; only the independently qualified V/N and NUM bodies are claimed here.
