title: Run Comanche Executive job services as native routines
date: 2026-10-12T17:30Z
lane: A
---
Comanche055 SPVACIN, SPVAC, CHANG1, CHANG2, JOBSLEEP, JOBWAKE, PRIOCHNG and ENDOFJOB are routines of the control-transfer ABI (`cm_exec_job_routines`). Each composes the qualified image body of its source path and leaves Z where the original continues: the caller, the selected basic job, NEWOPS for an interpretive job, the idle loop ADVAN, or JOBWAKE's TC 014 and CCSHOLE exits. All 6,144 cases equal the original Comanche055 program in yaAGC in all 2,048 erasable words, SUPERBNK, the interrupt-enable bit and channel 11. The cases are 1,024 per service group, drawn from each body's qualified input generator, and they reach every kind of continuation and the SPVAC alarms. The 12,306 strict and sanitizer checks pass, and every sixteenth case matches in VICE. With `cm-exec-services`, every EXECUTIVE.agc service that other code calls is now a native routine; the idle loop (ADVAN) is not yet registered. See `docs/CM-EXEC-JOBS.md`.
