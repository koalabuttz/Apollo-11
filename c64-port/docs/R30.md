# Translate R30 (Luminary099 and Comanche055)

Lane E (targeting). Milestone `r30`. How the routines are made and checked: `docs/INTERP-COMPILE.md`.

`Luminary099/R30.agc` (`src/lm_r30.c`, bank 22) and `Comanche055/R30.agc` (`src/cm_r30.c`, bank 23) are native C in full. Both are compiled by `tools/interp_compile.py` (spec `r30` in `tools/interp_specs.py`), with 66 and 74 routines of the control-transfer ABI. R30 is V82, the orbit parameter display (HAPOX, HPER, TFF or -TPER). Each routine runs the file from its entry, or from where it resumes, to the point where control leaves the file.

## Scope

Both missions, with the same labels:

| Routines | Source | Leaves at |
|---|---|---|
| V82CALL, V82GOFF and the GOXDSPF answers | option display, vehicle choice, TICKTEST start | BANKCALL GOXDSPF, WAITLIST, FINDVAC, ENDEXT |
| V82GOFLP, V82STALL, FLAGGON and the GOXDSPF answers | the recycle loop and N44 display | FINDVAC, BANKCALL DELAYJOB/GOXDSPF, B5OFF |
| V82GOFF1, OTHSHIP, BOTHSHIP, THISSHIP, EARTHPAD, MOONPAD, BOTHPAD, TICKTPER, TICKTFF | state vector update, the Earth/Moon constants (DLOAD* on X2), SR30.1, the time ticks | OTHPREC, THISPREC, RTB LOADTIME (native), ENDOFJOB |
| TICKTEST, DOTICK, TFFTICK, TPERTICK | the once-a-second Waitlist task, with its INDEX A; TC +1 jump table on V82FLAGS | WAITLIST, NOVAC, TASKOVER |
| V82GON, V82REDSP, V82GON1, NEXTLINE, MOONGON, EARTHGON, V82GON2, V82GON3 (CM: CANDEL, SPLRET) | the P00-mode variant with its own job | FINDVAC, BANKCALL, CHANG1, CHECKMM (CM), ENDEXT |
| SR30.1, TFFCALLS, STORHAPO, STORHPER, DOTPER, SKIPTPER, MAXCHK | apocenter, pericenter, period and time-of-free-fall | TFFCONMU, TFFRP/RA, CALCTPER, CALCTFF, the caller |

RTB LOADTIME runs the native `rtb_angles(..., RTB_LOAD_TIME)`. Destinations outside the file stop with `EXEC_UNMAPPED` until their files have routines.

The spec states the facts the cases need. GOXDSPF returns to one of three words after its CADR. BOTHSHIP and the THISSHIP return enter with X2 at 0 (Earth) or 2 (Moon), as THISPREC and OTHPREC leave it. TICKTEST's jump table has four entries, since A is V82FLAGS masked with THREE.

Compiler additions with this file (`tools/interp_compile.py`):
- A TC into the file whose return would land on interpretive or data words adds no return routine.
- `tc_tables` covers bounded INDEX; TC jump tables.
- `fixed_index` covers indexed fixed operands, which use the rope words at each address the given index values reach, and refuse any other address.
- `returns` gives a BANKCALL target that returns to several words.

`tools/interp_routine_differential.py` now defines every KEEP word of a mission with more than 60 routines. Before this, a C64 group silently kept every routine past the 60th. The earlier specs' generated files are unchanged.

## Evidence

Hashes: `evidence/r30/SHA256.json`. Bulk files are assets of the `evidence-r30` release.

- **Source map.** `r30-source-map.json` lists every word with the routine that compiles it: 261 Luminary words and 283 Comanche words, none untranslated.
- **Independent assembly comparison.** `make r30-differential`: 512 states per routine (71,680 cases) equal yaAGC in Z, all 2,048 erasable words and the interrupt-enable state. Every 128th case is frozen in `tests/r30_vectors.h`.
- **Host and sanitizer results.** `make test-r30 sanitize-r30` runs the 560 frozen cases (`r30-host.log`).
- **C64 execution results.** `make vice-r30` runs six diagnostics with 280 cases (`r30-vice.log`).
